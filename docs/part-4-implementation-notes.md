# Part 4 연속 추론 구현 기록

기준: [승인 커리큘럼](part-4-sequential-curriculum-design.md), 2026-10-06 사용자 구현 승인. 시작 커밋 59d4d7d.

## 실행 순서

1. 64화면·31문제, 대표 핸드/세 변형/종합 세 핸드 콘텐츠 → 독립 정답·후보 연속성·제출 전후 렌더링 검사.
2. 구판 Part 4 기록만 삭제, 구판 URL 안내 → 다른 Part 보존·새 기록 재삭제 방지·쓰기 실패 검사.
3. 단위·lint·빌드·브라우저 전체 흐름 → 최종 독립 검토, 문서 갱신, 한 번 커밋.

## 사전 결정

- 사용자 지정 바탕화면 폴더에서 직접 작업한다. 새 워크트리와 중간 커밋을 만들지 않는다.
- 기존 part4.ts의 사용자 변경은 체크 제목 한 줄이다. 새 구성에서도 체크만으로 강한 패를 제외하지 않는 설명을 보존한다. 전체 콘텐츠 교체와 직접 겹치는 변경이다.
- 공통 학습 엔진과 도식을 재사용하고, 후보 변화는 기존 상태 문구에 별도 줄로 적는다. 계산기·새 문제 UI를 만들지 않는다.
- 구판 레슨 ID와 개정판 ID를 분리한다. 구판을 카탈로그 검증 전에 정리해야 다른 Part까지 손상된 기록으로 초기화되는 일을 막을 수 있다.

## 검증 기록

- 구판 콘텐츠에서 신규 요구 테스트 42개가 실패하는 것을 확인한 뒤 구현하여 통과시켰다. 구판 URL·Q30 조건/도식 검사도 실패 재현 후 수정했다.
- 최종 전체 단위·컴포넌트 테스트: 38파일, 358개 통과.
- lint 통과. TypeScript 검사와 Vite 프로덕션 빌드 통과. JS 번들 526.36kB로 기존 500kB 경고는 남아 있다. 코드 분할은 이번 커리큘럼 범위에 포함하지 않았다.
- Part 4 브라우저 검사 20개에서 전체 화면·저장 복원·구판 정리·통과 경계를 통과했다. 첫 실행은 Windows 종료 단계에서 멈췄으므로 검사 완료와 실행기 종료를 구분했다. 해당 실행기만 종료하고 전체 브라우저 검사를 별도로 실행했다.
- 최종 전체 브라우저 검사: 모바일·데스크톱 Chromium 114개 통과, 실행기 정상 종료(3.7분). 문서 상대 링크 및 `git diff --check` 통과.
- 모바일 Q11·Q30, 데스크톱 Q14 캡처를 직접 확인했다. 실제 휴대전화 및 Safari/Firefox는 검증하지 않았다.

## 최종 검토와 결정

- 독립 검토에서 Q20·Q24 프리플랍 조건이 미래의 행동 흐름을 미리 알려주는 문제를 발견했다. 회귀 테스트 2개가 실패함을 확인하고 안내를 단계 이름으로 교체했다. 최종 358개 테스트에 포함되어 통과했다.
- 카드 사실·드로우·행동/팟·후보 연속성·조건부 정답·기록 정리에서 추가 수정 사항은 없었다. 실제 UI와 실행 결과는 검토자 대신 구현자가 별도 확인했다. 실제 상대 빈도나 GTO 최적성은 검증 대상이 아니다.
- Q30 및 변형 C는 레이즈 총액을 초기 팟에 대한 단순 베팅 비율로 표시하지 않는다. 기존 행동 이력과 문제 조건에 초기 팟·베팅·레이즈 총액을 명시한다. 새 레이즈 전용 도식을 만들지 않는 최소 변경이다.
- 기존 사용자 수정 제목 ‘체크했다는 이유만으로 강한 패를 지우지 않아요’를 레슨 6의 네 번째 화면에 보존했다.
- `LearningSession`을 재사용하고 상태 문구의 줄바꿈만 추가했다. 문제 전용 화면이나 추론 계산기를 추가하지 않았다.
- 구판 기록은 현재 카탈로그 검사 전에 정리한다. 전환 저장 실패 시 원본을 삭제하지 않으며 경고를 표시한다. 새 ID에는 삭제가 다시 적용되지 않는다.
