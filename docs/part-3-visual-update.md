# Part 3 짧은 설명·시각화 작업

2026-10-04 사용자 승인. 기존 7레슨·68단계·24문제의 ID·종류·순서·카드·정답·보기 ID와 배치는 유지한다. 추가연습·확률 계산기·저장 정책은 추가하지 않는다.

## 실행 계획과 검증

1. 현재/가능성, 무늬 장수, 숫자 순서, 아웃츠 계산, 남은 기회를 정적 도식으로 표시 → 렌더러 테스트에서 카드 소속·숫자 관계·확률 조건 확인.
2. 7레슨 설명·선택지·해설 축약 → 핵심 정의·백도어 조건·미확인 후보·완성/승리 구분 유지. 퀴즈 제출 전 정답 도식 없음.
3. 단위 테스트·lint·빌드·모바일/데스크톱 브라우저 검증 → 이전·다음·새로고침 복원, 가로 넘침, 24문제 채점 확인.

## 구현 판단

- 사용자 확정에 따라 바탕화면 폴더에서 작업한다. 새 워크트리·커밋·push는 하지 않는다.
- 계산·숫자·기회 그림은 콘텐츠가 제공한 고정 값만 그린다. 자동 족보 판정이나 확률 계산은 없다.
- 기존 카드 테이블은 유지한다. 숫자 띠는 카드 자체가 아니라 숫자 관계이며, 기다리는 숫자는 글자로도 표시한다.
- 확률마다 기회와 조건을 붙인다. 플랍에서 두 장은 턴 또는 리버 중 적어도 한 번 완성, 턴에서 빗나간 뒤는 리버 한 장이다. 백도어의 두 장 모두 필요한 조건과 구분한다.

## 진행 기록

- 시작: 기존 변경 사항과 공통 규칙 확인. 변경 전 파일의 카드·문제·순서와 기존 콘텐츠 테스트를 비교 기준으로 사용.
- 도식 테스트: 신규 10개 중 9개 실패(새 그림 없음) 확인 후 구현하여 10개 통과. 기본 테스트 프로세스가 지연되어 원인 조사 스킬 적용, threads 실행으로 같은 실패와 통과 확인. 앱 설정은 바꾸지 않음.
- 구현: 정적 도식 3종, 테이블 설명에서 보조 도식 표시, 7레슨의 긴 설명 축약. 저장·채점 엔진과 문제 데이터의 의미는 유지.
- 검증 1: 단위·컴포넌트 전체 220개, lint, 빌드 통과. Part 3와 완성 카드 맥락 브라우저 24개 통과. 7레슨 전체 단계, 24문제 정답 채점, 제출 후 선택·해설 복원, 홈 복귀와 이전·다음, 종합 4/6·5/6 경계 확인.
- 화면 확인: Chromium 390×844·1440×900, 새 도식은 320px 너비도 넘침 검사. 모바일 현재/가능성, 스트레이트 숫자 띠, 확률 화면의 스크린샷 직접 확인.
- 최종 독립 코드 검토: Critical/Important/Minor 제품 결함 없음. 고정 후보 카드·백도어/일반 드로우·확률 조건·퀴즈 힌트·CSS·신규 테스트 검토.
- 검증 한계: 변경 전 독립 데이터 스냅샷 명령은 문법 오류로 실패했으므로 전후 자동 비교 성공으로 간주하지 않음. 카드·ID·순서·정답 보존은 적용 패치 검토와 기존 콘텐츠 테스트로 확인. 실제 기기·Safari·Firefox·스크린리더는 미검증.
- 최종 전체 회귀: Chromium 모바일·데스크톱 브라우저 80개 모두 통과. 기존 Part 0·1·2 및 추가연습의 학습·목록 이동·복원·오답 리뷰 포함. 바탕화면 폴더에 미커밋 상태로 반영하며 커밋·push·배포는 하지 않음.
