# 학습 문구 개선 기록

## 목적과 점검 범위

파트 3의 완성 확률 설명에서 ‘플랍 → 리버까지 두 장’이 무엇을 뜻하는지 불명확했던 것을 계기로, 파트 0~3의 레슨 27개와 파트 1·2의 연습 문제 데이터 86개를 점검했다.

이미 충분히 설명된 문장은 유지하고, 조건·용어의 뜻·이유가 생략되어 입문자가 오해할 수 있는 문장을 보충했다. 레슨 단계 52곳과 연습 데이터의 설명·문제 조건 8곳을 수정했다. 연습의 공통 설명 한 곳은 여러 문제에 함께 적용된다.

## 보충한 설명

| 범위 | 주요 내용 |
| --- | --- |
| 파트 0 | 보드와 개인 카드, 최종 다섯 장 구성, 턴·리버의 카드 수, 행동의 조건, 블라인드와 행동 순서 |
| 파트 1 | 카드 표기, 높은 카드·포켓 페어·같은 문양·연결된 숫자의 뜻, 포지션, 키커, 시작패 판단의 전제 |
| 파트 2 | 현재 족보의 구성, 탑·미들·바텀 페어, 셋, 보드가 상대의 완성 패에 주는 가능성 |
| 파트 3 | 드로우와 완성 패의 차이, 필요한 숫자와 실제 카드 수, 아웃츠 중복, 확률의 사건·시점·전제, 근사 계산과 한계 |
| 파트 1·2 연습 | 포지션 문제의 조건과 용어, 카드 예시가 해당 족보를 만드는 이유 |

## 완성 확률 화면의 기준

- ‘다음 턴 한 장’은 바로 다음 턴 카드로 드로우가 완성될 확률이다.
- ‘리버까지 두 장’은 턴과 리버를 모두 볼 때, 둘 중 적어도 한 장으로 완성되는 경우를 포함한다. 턴에 이미 완성된 경우도 포함하며, 두 장 모두 같은 문양이어야 한다는 뜻이 아니다.
- ‘턴에서 빗나간 뒤 리버 한 장’은 턴에 완성되지 않은 상황에서 마지막 리버 카드로 완성될 확률이다.
- 이 수치는 드로우 완성 확률이며, 상대를 이기거나 돈을 딸 확률이 아니다. 약 35%라는 수치가 매번 정해진 횟수의 성공을 보장하지 않는다.
- 처음부터 필요한 카드 두 장을 모두 맞혀야 하는 백도어 드로우와 구분한다.

## 유지한 사항과 검증

카드 예시, 문제·선택지 ID, 정답과 보기, 단계 순서·수, 저장·복원 로직은 변경하지 않았다. 설명 필드를 제외한 데이터의 수정 전후 비교로 기존 구성을 유지했는지 확인했다.

검증 결과: 정적 검사와 빌드 성공, 단위 테스트 156개 통과, 모바일·데스크톱 Chromium 흐름 테스트 36개 통과. 확률 화면의 모바일 스크린샷에서도 문장과 목록이 화면 너비 안에 표시되는 것을 확인했다. 실제 기기와 Safari·Firefox는 이번에 검증하지 않았다.

앞으로의 문구 작성 기준은 [커리큘럼 구현 공통 규칙](curriculum-conventions.md)을 따른다. 용어를 길게 나열하기보다 뜻·조건·카드 예시의 이유를 짧은 문장과 목록으로 설명한다.
