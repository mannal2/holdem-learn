## 최신 교육 보완 (2026-10-05)

아래 상세 설계는 최초 구현의 기록이다. 이후 승인한 [교육 보완 계획](part-4-revision-plan.md)이 변경된 화면·문제의 현재 기준이며, 같은 항목에서는 최신 계획을 우선한다. 페이지 수·순서·종합 통과 기준은 유지한다.

- 레슨 1은 K♠ 8♠ 3♣에서 셋·원 페어·페어 없는 패를 비교하고 플러시 드로우를 별도 가능성으로 보여준다.
- 레슨 2는 자리 그림에 시작패 예시를 추가한다. 재레이즈 문제는 실제로 관찰한 강한 시작패의 경향을 판단한다.
- 레슨 3 제목은 ‘공용 카드로 가능한 상대 패를 살펴봐요’이며 현재 패와 앞으로의 가능성을 구분한다.
- 레슨 4는 드로우의 콜과 셋의 체크가 가능한 이유를 묻는다. ‘상대’는 항상 내가 관찰하는 플레이어다.
- 레슨 5는 ‘큰 베팅 뒤 확인한 패가 대부분 강했다’는 관찰을 사용한다. 반대 방향의 관찰로 추론하지 않는다.
- 레슨 6은 A K♥ Q♥ / B J♠ 10♠ / C 8♣ 8♦를 고정한다. 충돌 카드는 별도 확인용 후보이며 턴 베팅 전 팟·베팅액·관찰 조건으로 A를 더 주의한다.
- 종합 4~6번째 문제는 콜의 이유·관찰한 성향·턴의 가능성 비교를 확인한다. 후보를 확정하거나 모든 후보의 가능성이 같다고 가르치지 않는다.

의미가 변경된 Q05·10·11·14·18·22·23·24는 `-v2` 문제·보기 ID를 사용한다. 과거 완료·최고 점수는 유지하고 변경된 문제의 진행 중 답만 정리한다. 최신 결과를 다시 만들 때는 변경된 문제도 풀어야 한다.

## 2. 공통 화면·교육 원칙

### 짧은 글과 필요한 그림

- 한 화면에서 한 가지 판단만 배운다. 본문은 한두 문장, 해설은 핵심 이유 한두 문장으로 제한한다.
- 카드 이름·행동 순서를 본문과 그림에 반복하지 않는다. 이 문서의 제작 지침을 학습 화면에 노출하지 않는다.
- 본문의 글자 수를 줄이기 위해 필요한 조건까지 지우지 않는다. 인원·자리·앞선 행동은 짧은 상황 표시로 둔다.
- 카드·칩·자리 도식은 기존 디자인을 재사용한다. 생성형 이미지나 실제 사진이 필요하지 않다.
- 모바일은 위에서 아래로 공용 카드 → 짧은 행동 기록 → 후보 → 질문 순서다. 후보 2장은 한 묶음, 후보끼리는 별도 작은 상자로 구별한다.
- 후보는 보통 2~3개, 비교 학습에 필요한 경우 최대 4개다. 큰 레인지 격자표·퍼센트·콤보 계산은 도입하지 않는다.
- 색과 함께 글자·테두리로 상태를 표시한다. 문제 제출 전에는 정답 후보나 족보를 강조하지 않는다.

### 후보의 의미

- 후보 영역의 고정 제목은 **가능한 상대 패 예시**다. 후보마다 ‘예시’를 붙이거나 같은 안내를 반복하지 않는다. 그림 속 후보는 전체 레인지나 실제로 공개된 상대 패를 뜻하지 않는다.
- 후보 A와 후보 B는 동시에 배분된 패가 아니다. 서로 같은 카드를 포함할 수 있으나 각 후보 내부와 실제 공개 카드 사이에는 중복이 없어야 한다.
- 상대 실제 패는 뒤집어 공개하지 않는다. 채점은 당시 정보에 맞는 판단을 기준으로 한다.
- 내 카드가 판단에 필요 없는 화면에는 임의의 내 카드를 넣지 않는다. 레슨 6처럼 실제 내 카드가 있으면 기존 별도 영역으로 표시한다.
- ‘강함/중간/약함’은 보드와 상황에 따른 상대적인 설명이다. 현재 족보와 드로우 여부를 먼저 표시한다. 원 페어와 드로우는 함께 존재할 수 있다.
- 후보가 존재한다는 것과 그 후보가 자주 나온다는 것을 구분한다. 아무 근거 없이 같은 확률·특정 확률을 부여하지 않는다.

### 추론 문제의 정답 기준

- 카드로 확인하는 사실: 족보, 드로우, 공개 카드와 충돌하는 후보, 팟 대비 크기.
- 조건에 근거한 경향: 같은 상대·비슷한 조건에서의 자리 비교, 문제에서 명시한 관찰 성향.
- 단정할 수 없는 것: 베팅 크기 하나만으로 실제 패 확정, 체크·콜만으로 강한 패 제거.
- 성향 조건은 해당 독립 문제에도 표시한다. 사용자가 앞 페이지의 조건을 기억해야 정답이 결정되는 문제를 만들지 않는다.
- 정답은 보기 길이로 눈치챌 수 없도록 비슷한 길이로 쓴다. 2지선다 외에 카드 후보 3지선다와 복수 선택을 섞는다.
- 레슨 보기는 고정하며 아래 순서를 따른다. 정답 위치는 레슨별로 분산한다.
- 복수 선택은 “모두 고르세요”를 명시한다. 제출 후에는 원래 카드·조건을 유지하며 필요한 근거만 공개한다.

## 3. 레슨 1 — 상대 패는 하나로 정할 수 없어요

핵심: 베팅 한 번으로 상대 패 두 장을 맞힐 수는 없다. 여러 후보를 남긴다.

설명 상황 S1: 플랍 K♠ 8♦ 3♣. 두 사람만 남았고 상대가 먼저 베팅했다. 후보는 A♥ K♦, 8♣ 8♥, A♣ Q♦. 이 후보들은 행동에 가능한 이유를 보여주는 예시이며 등장 빈도를 비교하지 않는다.

| 페이지 | 화면 제목 | 화면 문구 / 구성 |
|---|---|---|
| 1 | 베팅했으니 AK일까요? | “베팅만 보고 상대의 두 장을 정할 수는 없어요.” S1 보드와 상대 베팅 표시. 후보는 아직 없음. |
| 2 | 같은 베팅, 다른 패 | “원 페어로도, 셋으로도 베팅할 수 있어요.” S1에서 AK·88 두 후보와 족보 표시. |
| 3 | 페어가 없어도 베팅해요 | “상대가 포기하기를 바라며 베팅할 수도 있어요. 이런 시도를 블러프라고 해요.” 같은 보드, AQ 후보. |
| 4 | 여러 후보를 함께 생각해요 | “상대가 가질 수 있다고 생각하는 패의 범위를 레인지라고 해요.” 세 후보를 다시 모아 표시. |
| 5 | Q01 | 아래 문제. |
| 6 | Q02 | 아래 문제. |
| 7 | 핵심 정리 | “여러 후보를 남기고, 다음 정보를 기다려요.” 후보 묶음 아이콘과 핵심 한 문장. |

### Q01 · 베팅을 보고 할 수 있는 판단

- 그림·조건: S1 보드와 베팅만 표시. 후보·족보 표시 없음.
- 질문: 상대가 베팅했어요. 어떤 판단이 맞을까요?
- 보기: ① 반드시 AK예요. / ② 여러 종류의 패가 가능해요.
- 정답: ②.
- 해설: “같은 베팅도 원 페어·셋·블러프에서 나올 수 있어요.”
- 제출 후: AK·88·AQ 예시를 카드로 표시. 별도 반복 설명 상자는 없음.

### Q02 · 레인지의 뜻

- 그림: 서로 분리한 A♠ J♦ / J♣ J♥ / K♣ Q♣ 후보. 보드 없음.
- 질문: 여러 상대 패를 후보로 생각하는 이유는 무엇일까요?
- 보기: ① 아직 실제 패를 모르기 때문이에요. / ② 세 패의 가능성이 똑같기 때문이에요.
- 정답: ①.
- 해설: “후보를 함께 남긴다는 뜻이지, 가능성이 모두 같다는 뜻은 아니에요.”
- 제출 후: 추가 그림 없음.

## 4. 레슨 2 — 자리와 첫 행동에서 출발해요

핵심: 자리와 앞선 행동을 연결해서 읽는다. 시작패 표를 암기시키지 않는다.

공통 비교 조건: 6인 테이블, 같은 상대, 비슷한 보유 칩. 앞에 참가한 사람 없이 첫 레이즈를 하는 장면끼리 비교한다. 자리 설명은 ‘초반 자리(UTG)’와 ‘딜러 버튼’으로 표시한다. 일반적인 참가 경향을 설명하는 예시이며 정확한 카드 범위를 지정하지 않는다.

| 페이지 | 화면 제목 | 화면 문구 / 구성 |
|---|---|---|
| 1 | 뒤에 몇 명이 남았나요? | “뒤에 결정할 사람이 많을수록 시작패를 더 신중하게 고르는 편이에요.” 초반 자리와 뒤의 다섯 자리 표시. |
| 2 | 후반에는 더 넓게 참가할 수 있어요 | “앞선 사람들이 모두 폴드했다면, 버튼에서는 더 다양한 패로 참가할 수 있어요.” 앞 세 자리 폴드, 버튼, 뒤 SB·BB 표시. |
| 3 | Q03 | 동일 조건의 자리 비교. |
| 4 | 먼저 올린 건가요, 다시 올린 건가요? | “첫 레이즈와 재레이즈는 앞선 상황이 달라요.” ‘모두 폴드 → 레이즈’와 ‘앞사람 레이즈 → 재레이즈’ 두 행동 띠. |
| 5 | Q04 | 앞선 행동 구분. |
| 6 | 콜에도 여러 패가 있어요 | “콜만 보고 작은 페어라고 정할 수는 없어요.” 서로 다른 후보 7♣ 7♦ / A♠ J♠. 특정 조건의 콜 권장표는 아님. |
| 7 | Q05 | 재레이즈의 해석. |
| 8 | 핵심 정리 | ‘상대 자리 → 앞선 행동 → 상대 행동’ 세 칸. |

### Q03 · 같은 상대, 다른 자리

- 그림·조건: 공통 비교 조건을 함께 표시. A: UTG 첫 레이즈. B: 앞 세 사람 폴드 후 버튼 첫 레이즈. 두 자리 그림을 같은 크기로 제시.
- 질문: 일반적으로 더 다양한 패로 참가할 수 있는 쪽은 어디일까요?
- 보기: ① A · 초반 자리 / ② B · 딜러 버튼.
- 정답: ②.
- 해설: “버튼은 뒤에 두 사람만 남아, 초반보다 다양한 패로 첫 레이즈를 할 수 있어요.”

### Q04 · 앞선 행동 읽기

- 그림: A는 앞사람 레이즈 → 상대 콜. B는 앞사람 레이즈 → 상대 재레이즈. 자리·패의 강약 비교는 하지 않음.
- 질문: 앞선 레이즈 금액을 다시 올린 장면은 무엇인가요?
- 보기: ① B · 재레이즈 / ② A · 콜.
- 정답: ①.
- 해설: “재레이즈는 앞사람이 올린 금액을 다시 높이는 행동이에요.”
- 목적: 뒤 레슨에서 행동 기록을 정확히 읽기 위한 확인 문제.

### Q05 · 재레이즈하면 항상 AA일까요?

- 그림·조건: 프리플랍, 한 사람 레이즈 → 상대 재레이즈. 상대의 특별한 성향은 모름.
- 질문: 상대 후보를 어떻게 생각할까요?
- 보기: ① AA만 남겨요. / ② 여러 후보를 남겨요.
- 정답: ②.
- 해설: “AA 외의 강한 패나 블러프로도 재레이즈할 수 있어요.”
- 제출 후: 추가 카드 목록 없음. 모든 재레이즈에 블러프가 같은 비중으로 있다는 뜻은 아님.

## 5. 레슨 3 — 공용 카드가 후보를 바꿔요

핵심: 후보의 현재 족보와 좋아질 가능성을 분리해서 읽는다.

설명 상황 S3: 플랍 Q♠ 8♠ 3♦. 후보 Q♥ J♣(탑 페어), 8♥ 8♦(셋), A♠ J♠(플러시 드로우), A♥ K♣(현재 페어 없음).

| 페이지 | 화면 제목 | 화면 문구 / 구성 |
|---|---|---|
| 1 | 같은 공용 카드, 다른 족보 | “상대 후보마다 만들어지는 패가 달라요.” S3 보드와 QJ·88 두 후보, 각 족보. |
| 2 | 아직 완성되지 않은 후보도 있어요 | “지금의 족보와 앞으로의 가능성을 함께 봐요.” 같은 보드, A♠ J♠와 A♥ K♣ 비교. ‘페어 없음 + 플러시 드로우’ / ‘페어 없음’ 표시. |
| 3 | Q06 | 셋 후보 선택. |
| 4 | Q07 | 플러시 드로우 후보 선택. |

### Q06 · 셋이 되는 후보

- 그림: S3 보드. 후보 A: Q♥ J♣ / B: 8♥ 8♦ / C: A♠ J♠. 족보 이름 없음.

### Q07 · 플러시 드로우 후보

- 보기: ① 후보 A / ② 후보 B / ③ 후보 C.

- 해설: “A♠ J♠는 공용 카드와 합쳐 스페이드가 네 장이에요.”
- 제출 후: 네 스페이드의 근거 표시. 완성된 다섯 장 강조와 구별.

### Q08 · 페어와 드로우 함께 보기

- 그림: 보드 K♦ 8♦ 3♦, 후보 K♣ A♦. 이름·상태 표시 없음.

- 정답: ②·③.
- 해설: “K 원 페어가 있고, 다이아몬드 한 장이 더 나오면 플러시도 완성돼요.”
- 제출 후: ‘현재: 탑 페어 / 가능성: 플러시 드로우’. 그림을 반복하지 않음.

## 6. 레슨 4 — 같은 행동에도 여러 이유가 있어요

핵심: 행동을 후보 하나와 일대일로 연결하지 않는다.

설명 상황 S4: 플랍 K♥ 9♥ 4♣, 플랍에 두 사람만 남음. 베팅 설명에는 K♣ Q♦(탑 페어)와 A♥ J♥(플러시 드로우)를 사용한다. 드로우 베팅은 상대의 폴드와 이후 개선을 모두 기대할 수 있다고 짧게 설명한다.

| 1 | 좋은 패로 더 받을 수 있어요 | “좋은 패를 가진 상대는 칩을 더 받으려고 베팅할 수 있어요.” S4와 KQ 후보. |
| 2 | 드로우로도 베팅할 수 있어요 | “지금 상대가 포기해도 좋고, 다음 카드로 좋아질 수도 있어요.” 같은 보드와 A♥ J♥ 후보. |

| 5 | Q10 | 콜한 뒤에도 남는 후보. |

### Q09 · 베팅의 두 가지 이유

- 질문: 상대가 베팅할 수 있는 이유를 모두 고르세요.

- 정답: ①·③.
- 해설: “탑 페어로 더 받으려 하거나, 드로우로 상대의 폴드를 기대할 수 있어요.”

### Q10 · 콜했다면 드로우는 없을까요?

- 그림·조건: 플랍 Q♣ 10♣ 4♦. 나 베팅 → 상대 콜. 후보 A♣ 8♣.

- 정답: ①.

### Q11 · 체크와 강한 패

- 그림·조건: 플랍 A♦ 7♣ 2♠. 상대 체크. 후보 7♦ 7♥.
- 질문: 체크했다는 이유만으로 이 셋 후보를 지워도 될까요?

- 정답: ②.

## 7. 레슨 5 — 베팅 크기도 단서예요

핵심: 베팅은 베팅 전 팟에 비해 읽고, 크기의 의미는 주어진 정보와 연결한다.

팟은 ‘지금까지 가운데 모인 칩’으로 처음 한 번 설명한다. 모든 그림의 팟 금액은 상대가 이번에 베팅하기 **전** 금액이다. 같은 100 기준 막대로 두 상황의 비율을 비교한다. 팟에 실제로 쌓인 칩 수십 개를 그리지 않는다.

| 페이지 | 화면 제목 | 화면 문구 / 구성 |
|---|---|---|
| 1 | 가운데 모인 칩과 비교해요 | “팟은 지금까지 가운데 모인 칩이에요. 베팅은 팟에 비해 얼마나 큰지 봐요.” 팟 100 / 베팅 50, 절반 막대. |
| 2 | 같은 50칩도 달라요 | “팟이 다르면 같은 베팅도 비중이 달라요.” 팟 100·500에 각각 베팅 50. ‘절반’·‘10분의 1’ 표시. |
| 3 | Q12 | 같은 베팅의 상대적 크기. |
| 4 | 크게 걸어도 패는 확정되지 않아요 | “큰 베팅에는 강한 패뿐 아니라 블러프도 있을 수 있어요.” 강한 패 / 블러프 두 이유만 표시. 불필요한 보드 없음. |
| 5 | Q13 | 큰 베팅에서 단정할 수 없는 것. |
| 6 | 관찰한 습관을 함께 봐요 | “앞선 판에서 본 상대의 습관도 참고해요.” ‘여러 차례 확인: 강한 패일 때 큰 베팅을 자주 함’ → ‘이번 큰 베팅’ 도식. |
| 7 | Q14 | 명시한 상대 성향 적용. |
| 8 | 핵심 정리 | ‘팟 대비 크기 + 관찰한 행동’ 두 칸. 같은 경고를 다시 길게 반복하지 않음. |

### Q12 · 팟 대비 크기

- 그림: A는 베팅 전 팟 80·베팅 40. B는 베팅 전 팟 200·베팅 40. 동일 형식의 금액 그림. 정답 ‘더 큼’ 표시는 제출 후.
- 질문: 팟에 비해 더 큰 베팅은 어느 쪽인가요?
- 보기: ① A / ② B.
- 정답: ①.
- 해설: “A는 팟의 절반, B는 5분의 1을 베팅했어요.”
- 제출 후: 50%·20% 비율 막대. 계산 자체를 암기시키지 않음.

### Q13 · 큰 베팅만 봤을 때

- 그림·조건: 팟 100·상대 베팅 100. 상대의 성향은 모름.
- 질문: 이 정보만으로 할 수 있는 판단은 무엇인가요?
- 보기: ① 강한 패로 확정해요. / ② 강한 패와 블러프를 모두 고려해요.
- 정답: ②.
- 해설: “팟만큼 크게 베팅했다는 사실만으로 상대 패를 확정할 수는 없어요.”

### Q14 · 관찰한 성향 활용

- 그림·조건: ‘앞선 여러 판에서 강한 패로 큰 베팅을 자주 했어요.’ 팟 100·이번 베팅 100.
- 질문: 이번 큰 베팅은 어떻게 볼까요?
- 보기: ① 강한 패 쪽에 더 무게를 둬요. / ② 베팅 크기와 습관은 무시해요.
- 정답: ①.
- 해설: “앞서 본 습관 때문에 강한 패를 더 의심할 수 있어요.”
- 제작 주의: 모든 상대에게 적용할 규칙이 아님. 관찰 조건은 문제·해설 복원에도 유지. 구체적인 확률은 붙이지 않음.

## 8. 레슨 6 — 새로운 정보로 다시 판단해요

핵심: 실제 카드·행동을 연결하면서 후보의 상태와 판단을 갱신한다.

### 끝까지 유지할 상황 S6

- 6인 테이블. UTG·HJ·CO 폴드 → 상대 버튼 레이즈 → SB 폴드 → 나 BB 콜. 이후 두 사람만 남음.
- 내 카드 A♥ J♦. 프리플랍의 정확한 베팅액·보유 칩은 액션 추천을 묻지 않으므로 표시하지 않음.
- 플랍 J♥ 8♥ 2♣. 나 체크 → 상대 베팅 → 나 콜.
- 턴 4♥. 나 체크 → 상대 베팅. 여기서 판단을 마침. 콜·폴드 추천은 묻지 않음.
- 유효한 상대 후보 A: K♥ Q♥, B: J♠ 10♠, C: 8♣ 8♦. 레인지 일부 예시임.
- 플랍 상태: A 플러시 드로우 / B 탑 페어 / C 셋.
- 턴 상태: A 플러시 / B 탑 페어 / C 셋. B·C는 턴에 사라지지 않는다.
- 내 A♥는 플랍에서 보드와 하트 세 장, 턴에서 네 장이다. 내 플러시가 완성됐다고 강조하면 안 된다.

| 페이지 | 화면 제목 | 화면 문구 / 구성 |
|---|---|---|
| 1 | 출발한 상황을 기억해요 | S6 프리플랍 자리·행동·내 카드. “상대는 앞선 사람들이 폴드한 뒤 버튼에서 레이즈했어요.” |
| 2 | Q15 | 내 카드와 충돌하는 후보 제외. 프리플랍 상태. |

| 6 | Q17 | 플러시 완성 후보 선택. |
| 7 | 다시 베팅했어요 | 나 체크 → 상대 베팅 추가. “상대가 턴에도 베팅했어요.” 세 후보·턴 상태는 표시하되 특정 후보가 실제 패라는 강조 없음. |
| 8 | Q18 | 완성 플러시 주의와 나머지 후보 유지. |
| 9 | 핵심 정리 | ‘자리·첫 행동 → 플랍·행동 → 새 카드·행동’. “새 정보가 나오면 후보를 다시 평가해요.” |

### Q15 · 가질 수 없는 카드

- 그림: 내 A♥ J♦. 후보 A: A♥ Q♣ / B: K♥ Q♥ / C: 8♣ 8♦. 아직 공용 카드 없음.
- 질문: 내가 가진 카드 때문에 제외해야 하는 후보는 무엇인가요?
- 보기: ① 후보 A / ② 후보 B / ③ 후보 C.
- 정답: ①.
- 해설: “A♥는 내가 가지고 있어요. 상대가 같은 A♥를 가질 수는 없어요.”
- 제출 후: 내 A♥와 충돌하는 후보 A의 A♥에 같은 카드 표시. 후보 A는 실제 배분이 아니라 ‘불가능한 후보를 찾는 보기’임.
- 검증 예외: Q15 후보 A의 공개 카드 충돌은 의도된 오답 후보다. 구현 시 이를 명시한 데이터로만 허용하고 일반 후보 중복 검사를 끄지 않는다. 이후 상황 S6 후보에는 포함하지 않는다.

### Q16 · 플랍 베팅 뒤 남는 후보

- 그림·조건: S6 내 카드·플랍·세 유효 후보. 나 체크 → 상대 베팅. 앞선 버튼 레이즈는 짧은 이력으로 유지. 후보 상태 이름 없음.
- 질문: 베팅한 상대에게 가능한 패를 모두 고르세요.
- 보기: ① A · K♥ Q♥ / ② B · J♠ 10♠ / ③ C · 8♣ 8♦.
- 정답: ①·②·③.
- 해설: “드로우·탑 페어·셋 모두 베팅할 수 있어요.”
- 제출 후: 각 후보에 해당 상태만 표시. 동일 확률을 뜻하지 않음.

### Q17 · 턴에 달라진 후보

- 그림·조건: S6 보드에 턴 4♥ 추가, 세 후보 유지. 플랍 베팅·콜까지 이력 표시.
- 질문: 이번 턴에 플러시를 완성한 후보는 무엇인가요?
- 보기: ① B · J♠ 10♠ / ② C · 8♣ 8♦ / ③ A · K♥ Q♥.
- 정답: ③.
- 해설: “K♥ Q♥와 공용 카드의 하트 세 장이 플러시를 만들어요.”
- 제출 후: 보드와 후보 영역에서 해당 다섯 장만 강조. 후보를 따로 다섯 장으로 뽑아 재배치하지 않음.

### Q18 · 턴 베팅까지 연결하기

- 그림·조건: S6 턴. 나 체크 → 상대 베팅. 세 후보와 기존 카드·이력 유지.
- 질문: 지금의 후보를 어떻게 판단할까요?
- 보기: ① 플러시 후보만 남기고 나머지는 지워요. / ② 플러시를 주의하며 다른 후보도 남겨요.
- 정답: ②.
- 해설: “플러시를 주의해야 하지만, 탑 페어나 셋으로도 베팅할 수 있어요.”
- 제출 후: A ‘플러시 완성’, B·C ‘계속 고려’. 색상만으로 차이를 주지 않음.

## 9. 레슨 7 — 상대 패 추론 종합 도전

8화면: 안내 1 → Q19~Q24 → 요약 1. 설명 레슨과 다른 카드 상황으로 출제한다. 특정 질문의 정답이 다음 문제의 선행 조건이 되지 않는 독립 문제다.

안내: “새로운 상황에서 상대 후보를 살펴보세요. 총 6문제예요.”

### Q19 · 한 패로 단정하지 않기

- 그림·조건: 플랍 A♣ 9♦ 5♠, 두 사람만 남음, 상대 베팅. 상대 성향은 모름.
- 질문: 이 베팅을 어떻게 해석할까요?
- 보기: ① 상대는 반드시 AK예요. / ② A 원 페어·셋·블러프 등이 가능해요.
- 정답: ②.
- 해설: “베팅 한 번에 여러 패가 연결될 수 있어요.”
- 제출 후 후보 예시: A♦ Q♥ / 5♣ 5♦ / K♣ J♥. 예시 외 다른 후보도 가능.

### Q20 · 자리와 첫 행동

- 그림·조건: 6인, 같은 상대·비슷한 보유 칩. A: 앞 세 사람 폴드 후 버튼에서 첫 레이즈. B: UTG에서 첫 레이즈.
- 질문: 일반적으로 더 다양한 패가 포함될 수 있는 쪽은 어디일까요?
- 보기: ① A · 딜러 버튼 / ② B · 초반 자리.
- 정답: ①.
- 해설: “앞선 사람들이 폴드한 버튼에서는 초반보다 다양한 패로 참가할 수 있어요.”
- 제작: Q03과 좌우·보기 배치 반대. 카드가 없는 자리 개념 문제이므로 불필요한 시작패를 추가하지 않음.

### Q21 · 보드와 드로우 후보

- 그림: 플랍 10♦ 6♦ 2♠. 후보 A: 6♣ 6♥ / B: A♣ 10♠ / C: K♦ Q♦.
- 질문: 다이아몬드 한 장이 더 나오면 플러시가 되는 후보는 무엇인가요?
- 보기: ① 후보 A / ② 후보 B / ③ 후보 C.
- 정답: ③.
- 해설: “K♦ Q♦는 공용 카드와 합쳐 다이아몬드가 네 장이에요.”
- 제출 후: 네 장의 드로우 근거 표시.

### Q22 · 콜 뒤에도 남는 후보

- 그림·조건: 플랍 J♣ 8♦ 3♣. 나 베팅 → 상대 콜. 후보 A: A♣ 7♣ / B: J♦ Q♥. 두 사람만 남음.
- 질문: 콜한 상대에게 가능한 후보를 모두 고르세요.
- 보기: ① 후보 A / ② 후보 B / ③ 두 후보 모두 콜할 수 없어요.
- 정답: ①·②.
- 해설: “플러시 드로우로 다음 카드를 보거나, 탑 페어로 따라갈 수 있어요.”
- 제출 후: A 플러시 드로우 / B 탑 페어. 콜이 최선이라는 전략 문제는 아님.

### Q23 · 큰 베팅과 상대 정보

- 그림·조건: 베팅 전 팟 120·상대 베팅 120. ‘앞선 여러 판에서 강한 패로 큰 베팅을 자주 했어요.’
- 질문: 이번 큰 베팅은 어떻게 볼까요?
- 보기: ① 블러프라고 확정해요. / ② 강한 패 후보에 더 무게를 둬요. / ③ 관찰한 습관을 무시해요.
- 정답: ②.
- 해설: “앞서 본 습관 때문에 강한 패에 더 무게를 둬요.”
- 제작: 크기만으로 강도를 확정한 것처럼 보이지 않게 관찰 조건을 반드시 유지.

### Q24 · 새로운 카드로 갱신하기

- 그림·조건: 두 사람만 남음. 플랍 Q♦ 9♣ 2♦에서 나 베팅 → 상대 콜. 턴 5♦에서 나 체크 → 상대 베팅.
- 후보 A: A♦ 7♦ / B: Q♥ J♠. 내 카드는 이 문제에서 필요 없으므로 표시하지 않음.
- 그림 배치: 최종 보드 Q♦ 9♣ 2♦ 5♦에 ‘턴’ 표시, 짧은 행동 이력, 후보 두 개. 플랍 상태는 ‘이전’ 작은 글자로 확인 가능하게 하되 정답 족보는 공개하지 않음.
- 질문: 턴이 나온 뒤 올바른 판단은 무엇인가요?
- 보기: ① A는 플러시가 됐고, B도 후보로 남아요. / ② A만 가능하므로 B는 반드시 제외해요. / ③ A는 아직 플러시 드로우예요.
- 정답: ①.
- 해설: “A는 다이아몬드 다섯 장을 만들었어요. 턴 베팅만으로 B를 지울 수는 없어요.”
- 제출 후: A의 플러시 다섯 장 강조, B ‘계속 고려’.

마지막 요약 제목은 ‘핵심 정리’다. 본문: “상대 패를 하나로 정하지 않고, 자리·카드·행동으로 후보를 다시 살펴봐요.” 동일한 주의 문구를 세 문장씩 반복하지 않는다.

## 10. 구현 시 재사용과 필요한 확장

- 기존 `LearningSession`, 단일·복수 선택, 결과·저장·복원·이동을 사용한다. Part 4용 세션이나 페이지를 복제하지 않는다.
- `PlayingCard`, 기존 카드 영역 디자인, 자리 그림·칩 스타일을 재사용한다.
- 기존 테이블 타입은 내 카드 2장이 필수다. 관찰자 화면을 만들기 위해 임의의 내 카드를 넣으면 안 된다. 구현 시 상대 후보 도식은 공용 카드와 선택적인 내 카드, 서로 다른 후보를 명확히 지원하도록 한다.
- 필요한 표현은 상대 후보와 상태, 짧은 행동 이력, 팟·베팅 비교다. 기존 도식으로 가능한 것은 재사용하고 부족한 표현만 공통 도식에 추가한다. 자동 레인지 계산기·드래그 정렬·후보 편집 기능은 만들지 않는다.
- 후보별 카드 상태와 강조는 정적 콘텐츠로 정한다. 추론 확률·최적 전략을 계산하지 않는다.
- 퀴즈 제출 전에는 후보의 정답 족보·완성 강조·제외 표시가 숨겨져야 한다. 설명 화면은 교육에 필요한 상태를 즉시 표시한다.
- 레슨 6의 화면은 같은 상황 데이터를 바탕으로 구성하되 각 단계는 저장·복원이 가능한 독립 콘텐츠다. 이전 답을 틀렸다고 이후 카드나 질문이 바뀌지 않는다.
- Q15의 의도적인 충돌 후보만 구분한다. 정상 후보는 각자 내 카드·보드와 중복되는지 검사한다. 별개의 후보들끼리 같은 카드를 쓰는 것은 허용한다.
- 상대 후보를 실제 상대 카드 영역에 모두 올리지 않는다. 카드 출처를 구별하고 복원·오답 리뷰에도 같은 의미를 유지한다.

## 11. 구현 전·후 검토 기준

1. 콘텐츠 → 확인: 7레슨·56화면·24문제, 보기·정답·해설 연결, 종합의 새 사례와 정답 위치 분산.
2. 카드 → 확인: 족보·드로우·무늬 장수, 후보별 카드 충돌, S6의 내 카드·후보·행동 연속성.
3. 표현 → 확인: 문제 전 정답 힌트 없음, 그림과 본문 중복 없음, 후보 일부와 실제 상대 패의 구분.
4. 화면 → 확인: 모바일·데스크톱 카드 소속과 후보 읽기, 긴 문장·가로 넘침, 그림을 위한 불필요한 카드 추가 없음.
5. 흐름 → 확인: 기존 마지막 화면·선택·해설 복원, 홈·목록 복귀, 이전·다음, 종합 4/6 미통과·5/6 통과. 이전 Part 기록 유지.

이 문서는 승인한 상세 콘텐츠 기준이다.
