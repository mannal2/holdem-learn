# Part 3 상세 교육 설계 — 앞으로 좋아질 가능성 판단

작성일: 2026-10-02. 상태: 사용자 승인 후 레슨 7개·고정 퀴즈 24문제 구현 완료. 추가연습은 후속 작업으로 남긴다.

후속 표시 정책(사용자 승인): 레슨 1의 완성 플러시, 레슨 3의 두 완성 스트레이트, 레슨 6의 상대 플러시 비교는 5장만 떼어 보여주지 않는다. 원래 보드·개인 카드 위치를 유지하고 족보 구성 카드를 금색 테두리로 강조한다. 스트레이트 예시는 새 턴 카드가 보드에 추가됐음을 설명한다. 상대 비교는 같은 보드와 ‘가정한 상대 카드’를 구분하며 실제 공개 패가 아님을 명시한다. 아래 카드 목록은 족보 구성 설명이며 별도 5장 UI를 요구하지 않는다. 기존 단계 ID·순서·개수는 유지한다.

최종 검증: 단위·컴포넌트 150개, Chromium 모바일·데스크톱 브라우저 30개 통과. lint·빌드·변경 형식 검사 통과. 코드 설명은 `docs/code-walkthrough.md`의 14-1절, 실행 기록은 `docs/part-3-implementation-progress.md`에 정리했다.

## 1. 확정한 방향과 이번 범위

- 사용자 명칭은 **드로우**로 통일한다. 플러시 드로우, 스트레이트 드로우, 오픈엔디드 드로우, 거샷 드로우로 쓴다. 영어는 최초 설명에서만 괄호로 덧붙일 수 있다.
- 진행 순서는 레슨 상세 구성 확정 → 레슨 구현·검증 → 추가연습 설계·구현이다.
- 이번 설계는 기본 레슨 6개와 종합 도전 1개다. 기본 레슨은 각각 고정 퀴즈 3문제, 종합 도전은 새로운 카드의 고정 6문제로 총 24문제다.
- 추가연습 문제, 문제 풀, 링크, 시작 화면은 이번 구현에 넣지 않는다. 이전 대화의 48문제 안은 후속 논의용이며 확정 수량으로 취급하지 않는다.
- 대상은 Part 0·1·2 수준의 카드·족보·현재 패 판단을 학습한 입문자라고 가정한다. 이전 Part 완료를 새 접근 제한으로 강제하지 않는다.
- 콜·레이즈·폴드의 전략적 정답, 팟 오즈, 세미블러프, 상대 범위 추정은 다루지 않는다.
- 기본 레슨은 이해를 돕는 과정이며 통과 기준을 두지 않는다. 종합 도전만 기존 기준 80%를 사용한다. 6문제 중 5문제 이상이면 통과다.

학습자가 익힐 판단 순서:

1. 현재 완성된 족보를 확인한다.
2. 목표 족보를 완성할 카드의 숫자 또는 문양을 찾는다.
3. 공개 정보상 아직 보이지 않은 해당 카드의 장수를 센다.
4. 다음 한 장인지, 리버까지 두 장인지 구분한다.
5. 족보 완성과 실제 승리가 다른 판단임을 기억한다.

## 2. 공통 교육·화면 원칙

- 카드 표기는 내 카드 / 플랍 / 턴 / 리버를 구분한다. 아래 문서의 카드 문자는 실제 앱에서 기존 카드 컴포넌트로 표시한다.
- 설명 화면에서 필요한 카드는 강조할 수 있다. 퀴즈의 정답 근거 강조는 제출 뒤에만 표시한다.
- 설명 예시는 한 조건만 바꿔 비교한다. 퀴즈는 다른 카드에 개념을 적용하도록 구성한다.
- 각 문제는 하나의 핵심 판단을 묻는다. 여러 정답이 명확히 필요한 경우에만 기존 복수 선택을 쓴다.
- 선택지는 2~4개로, 실제 오개념을 대비한다. 모호한 강함/약함 등급은 묻지 않는다.
- 기본 화면 순서는 짧은 도입 → 카드 예시·비교 → 고정 퀴즈 3개 → 요약이다. 긴 레슨은 설명을 짧은 단계로 나눈다.
- 턴·리버 공개는 정해진 교육 사례다. 무작위 공개 몇 번으로 확률을 증명하지 않는다.
- 아웃츠는 이 파트의 기본 문제에서 '지정한 족보를 완성하는 미확인 카드 수'로 계산한다. 상대를 이기는 유효 아웃츠는 상대 패에 따라 달라질 수 있음을 레슨 6에서 설명한다.
- '9아웃츠'는 보이지 않는 하트 9장을 뜻한다. 상대 카드나 번 카드에 무엇이 있는지 알고 있다는 뜻도, 실제 남은 덱에 9장이 모두 있다는 단정도 아니다.
- 요약은 이름 목록 대신 사용자가 다음 카드 상황에서 실행할 판단을 알려준다.

## 3. 레슨 1 — 지금의 패와 앞으로의 가능성

제안 ID: `made-hand-and-draw`.

### 목표

현재 족보와 드로우를 분리하고, 원 페어와 드로우가 동시에 있을 수 있음을 이해한다.

### 화면 순서와 설명 문구

1. 도입: "Part 2에서는 지금 가진 패를 읽었습니다. 이제 어떤 카드가 나오면 좋아지는지도 살펴봅니다."
2. 플랍 예시: 내 카드 A♥ Q♥ / 플랍 9♥ 4♥ 2♣.
   - "현재는 A 하이입니다. 하트가 네 장이므로 아직 플러시는 아닙니다."
   - "하트 한 장이 더 나오면 플러시가 됩니다. 이렇게 완성을 기다리는 상태를 드로우(Draw)라고 합니다."
3. 성공 예시: 같은 내 카드·플랍에 턴 8♥.
   - 실제 완성 다섯 장 A♥ Q♥ 9♥ 8♥ 4♥를 함께 보여준다.
   - "이제 하트 다섯 장으로 플러시가 완성됐습니다."
4. 다른 결과 예시: 원래 플랍에 턴 8♣인 별도 가지.
   - "하트는 여전히 네 장입니다. 플러시가 완성되지 않았고 리버를 기다려야 합니다."
   - 앞 화면의 8♥를 8♣로 바꾼 대안임을 명시한다. 두 턴 카드를 같은 게임에서 연속으로 받은 것처럼 보여주지 않는다.
5. 아래 고정 퀴즈 3개.
6. 요약.

### 고정 퀴즈

**1-1. 현재 패와 가능성 구분**

- 내 카드: K♠ J♠ / 플랍: 8♠ 3♠ 2♦.
- 질문: "현재 패와 앞으로의 가능성을 올바르게 설명한 것은?"
- 보기: ① 이미 플러시다 ② 현재 K 하이이며, 스페이드 한 장이 더 나오면 플러시다.
- 정답: ②.
- 해설: "현재 스페이드는 네 장입니다. 족보는 K 하이이고, 스페이드 한 장으로 플러시가 완성될 수 있는 플러시 드로우 상태입니다."

**1-2. 원 페어와 드로우의 공존**

- 내 카드: K♥ Q♥ / 플랍: K♣ 8♥ 3♥.
- 질문: "이 패를 올바르게 설명한 것은?"
- 보기: ① K 원 페어이면서 플러시 드로우도 있다 ② 원 페어가 있으므로 드로우는 없다.
- 정답: ①.
- 해설: "K♥와 K♣로 원 페어가 있고, 하트 네 장으로 플러시 드로우도 있습니다. 현재 족보와 개선 가능성은 함께 설명할 수 있습니다."

**1-3. 가능성과 확정 구분**

- 질문: "플러시 드로우가 있다는 말은 플러시가 반드시 완성된다는 뜻일까요?"
- 보기: ① 반드시 완성된다 ② 필요한 카드가 나오지 않으면 완성되지 않는다.
- 정답: ②.
- 해설: "드로우는 가능성입니다. 필요한 문양이 턴과 리버에 나오지 않으면 플러시는 완성되지 않습니다."

### 요약 문구

"현재 패와 앞으로의 가능성을 따로 말해보세요. 드로우는 완성된 족보가 아니며, 원 페어와 드로우가 동시에 있을 수도 있습니다."

## 4. 레슨 2 — 플러시 드로우: 같은 문양을 함께 세기

제안 ID: `flush-draw`.

### 목표

내 카드와 공용 카드를 합쳐 같은 문양 네 장을 찾고, 다음 한 장으로 완성되는 경우와 두 장이 필요한 경우를 구분한다.

### 화면 순서와 설명 문구

1. 도입: "플러시는 같은 문양 다섯 장입니다. 플러시 드로우를 찾을 때도 내 카드와 공용 카드를 함께 봅니다."
2. 내 카드 두 장 사용: A♥ Q♥ / 플랍 9♥ 4♥ 2♣.
   - "내 카드의 하트 두 장과 보드의 하트 두 장, 합계 네 장입니다. 하트 한 장이 더 필요합니다."
3. 내 카드 한 장 사용: A♥ Q♣ / 플랍 9♥ 4♥ 2♥.
   - "내 카드 두 장이 같은 문양일 필요는 없습니다. A♥ 한 장과 보드 하트 세 장으로도 플러시 드로우입니다."
4. 두 장이 필요한 비교: A♥ Q♥ / 플랍 9♥ 4♣ 2♦.
   - "지금 하트는 세 장입니다. 턴 한 장만으로는 플러시가 될 수 없습니다. 턴과 리버가 모두 하트여야 합니다."
   - 백도어 드로우라는 이름은 보조 설명 한 번만 제시하고 암기·채점하지 않는다.
5. 아래 고정 퀴즈 3개.
6. 요약.

### 고정 퀴즈

**2-1. 필요한 문양 찾기**

- 내 카드: J♠ 9♠ / 플랍: K♠ 4♠ 2♦.
- 질문: "다음 한 장으로 플러시를 완성하는 문양은?"
- 보기: ① 하트 ② 스페이드 ③ 다이아몬드 ④ 클럽.
- 정답: ②.
- 해설: "스페이드가 네 장입니다. 아직 보이지 않은 스페이드 한 장이 나오면 같은 문양 다섯 장을 구성합니다."

**2-2. 내 카드 한 장을 쓰는 플러시 드로우**

- 내 카드: Q♦ 9♣ / 플랍: A♦ 6♦ 2♦.
- 질문: "내 카드 두 장의 문양이 다른데도 플러시 드로우가 있을까요?"
- 보기: ① 있다 ② 없다.
- 정답: ①.
- 해설: "Q♦와 보드의 다이아몬드 세 장을 합치면 네 장입니다. 다이아몬드 한 장이 더 나오면 플러시를 구성할 수 있습니다."

**2-3. 한 장과 두 장의 차이**

- 내 카드: K♣ J♣ / 플랍: 8♣ 5♦ 2♥.
- 질문: "턴에 클럽 한 장이 나오면 바로 플러시가 될까요?"
- 보기: ① 바로 플러시다 ② 아직 네 장이므로 리버에도 클럽이 필요하다.
- 정답: ②.
- 해설: "플랍까지 클럽은 세 장입니다. 턴에 클럽이 나와도 네 장이며, 플러시에는 다섯 장이 필요합니다."

### 요약 문구

"내 카드의 문양만 보지 말고 보드와 합쳐 세세요. 네 장이면 한 장이 더 필요하고, 플랍에서 세 장이면 두 장이 더 필요합니다."

## 5. 레슨 3 — 스트레이트 드로우: 양끝과 가운데 빈칸

제안 ID: `straight-draw`.

### 목표

문양 대신 숫자의 연결을 보고, 완성 카드의 숫자로 오픈엔디드와 거샷을 구분한다.

### 화면 순서와 설명 문구

1. 도입: "스트레이트는 문양과 상관없이 숫자가 이어지는 다섯 장입니다. 필요한 숫자부터 찾아봅니다."
2. 양끝 예시: 8♠ 7♦ / 플랍 6♣ 5♥ K♠.
   - 숫자 줄: `□ — 5 — 6 — 7 — 8 — □`.
   - "4 또는 9가 나오면 다섯 숫자가 이어집니다. 양끝이 열려 있는 상태를 오픈엔디드 드로우라고 합니다."
3. 가운데 예시: 같은 내 카드 / 플랍 5♣ 4♥ K♠.
   - 숫자 줄: `4 — 5 — □ — 7 — 8`.
   - "6이 나와야 가운데 빈칸을 채웁니다. 이런 상태를 거샷 드로우라고 합니다."
4. A 주의사항: "A는 A–2–3–4–5에서 낮게, 10–J–Q–K–A에서 높게 쓸 수 있습니다. K–A–2처럼 연결되지는 않습니다. A–2–3–4는 5만 기다리므로 양끝이 열린 예시로 분류하지 않습니다."
5. 아래 고정 퀴즈 3개.
6. 요약.

숫자 줄은 설명 문구로 표현할 수 있으며 별도 드래그·카드 정렬 기능을 요구하지 않는다. 완성 예시에서는 실제 다섯 장도 보여준다. 양끝 예시는 9♣을 더해 9♣ 8♠ 7♦ 6♣ 5♥, 가운데 예시는 6♦를 더해 8♠ 7♦ 6♦ 5♣ 4♥를 구성한다.

### 고정 퀴즈

**3-1. 양끝의 완성 숫자**

- 내 카드: Q♣ J♦ / 플랍: 10♥ 9♠ 3♣.
- 질문: "다음 한 장으로 스트레이트를 완성하는 숫자를 모두 고르세요."
- 복수 선택 보기: ① 8 ② K ③ Q ④ 7.
- 정답: ①·②.
- 해설: "9–10–J–Q가 이어집니다. 8이면 8부터 Q까지, K이면 9부터 K까지 스트레이트입니다. Q는 페어만 만들며, 7은 8이 여전히 빠져 있습니다."

**3-2. 가운데 빈칸**

- 내 카드: Q♣ 10♦ / 플랍: 9♥ 8♠ 3♣.
- 질문: "다음 한 장으로 스트레이트를 완성하는 숫자는?"
- 보기: ① 7 ② J ③ K.
- 정답: ②.
- 해설: "8–9–10–□–Q에서 J이 빠져 있습니다. 가운데 한 숫자가 필요한 거샷 드로우입니다."

**3-3. 연결돼 보여도 한 장으로는 부족**

- 내 카드: Q♣ J♦ / 플랍: 9♥ 5♠ 2♣.
- 질문: "턴에 10이 나오면 스트레이트가 바로 완성될까요?"
- 보기: ① 완성된다 ② 아직 9–10–J–Q 네 숫자라 한 장이 더 필요하다.
- 정답: ②.
- 해설: "턴에 10이 나와도 연결된 숫자는 네 개입니다. 스트레이트에는 연속된 다섯 숫자가 필요합니다."

### 요약 문구

"이름을 외우기 전에 필요한 숫자를 찾으세요. 양끝의 두 숫자를 기다리면 오픈엔디드, 가운데 한 숫자를 기다리면 거샷입니다."

## 6. 레슨 4 — 아웃츠: 숫자 종류가 아니라 카드 장수

제안 ID: `counting-outs`.

### 목표

지정한 족보를 완성하는 미확인 카드의 장수를 세고, 숫자 종류와 실제 카드 수를 구분한다.

### 화면 순서와 설명 문구

1. 도입: "필요한 카드가 몇 장인지 세면 개선 가능성을 비교할 수 있습니다. 이런 카드를 아웃츠(Outs)라고 부릅니다. 여기서는 문제에서 지정한 족보를 완성하는 카드만 셉니다."
2. 플러시 예시: A♥ Q♥ / 플랍 9♥ 4♥ 2♣.
   - "하트는 총 13장입니다. 이미 보이는 네 장을 빼면 9장입니다."
   - 남은 카드: K♥ J♥ 10♥ 8♥ 7♥ 6♥ 5♥ 3♥ 2♥. 실제 카드로 펼쳐 보여준다.
3. 오픈엔디드 예시: 8♠ 7♦ / 플랍 6♣ 5♥ K♠.
   - 4♠ 4♥ 4♦ 4♣ / 9♠ 9♥ 9♦ 9♣을 보여준다.
   - "필요한 숫자는 두 종류지만, 각 숫자는 네 문양이므로 총 여덟 장입니다."
4. 거샷 예시: 8♠ 7♦ / 플랍 5♣ 4♥ K♠.
   - 6♠ 6♥ 6♦ 6♣을 보여준다.
   - "필요한 숫자 한 종류에 네 문양, 총 네 장입니다."
5. 아래 고정 퀴즈 3개.
6. 요약.

### 고정 퀴즈

각 문제에 "상대 카드 등 추가 공개 정보는 없습니다. 지정한 족보를 완성하는 미확인 카드만 세세요"라는 조건을 짧게 표시한다.

**4-1. 플러시 아웃츠**

- 내 카드: K♦ J♦ / 플랍: 8♦ 4♦ 2♠.
- 질문: "다음 한 장으로 플러시를 완성하는 아웃츠는 몇 장인가요?"
- 보기: ① 4장 ② 9장 ③ 13장.
- 정답: ②.
- 해설: "다이아몬드 13장 중 이미 보이는 네 장을 제외하면 9장입니다. K이나 J의 다른 문양은 페어를 만들 수 있지만 플러시 아웃츠에는 포함하지 않습니다."

**4-2. 두 종류, 여덟 장**

- 내 카드: 9♣ 8♦ / 플랍: 7♥ 6♠ K♣.
- 질문: "5 또는 10이 나오면 스트레이트입니다. 스트레이트 아웃츠는 몇 장인가요?"
- 보기: ① 2장 ② 4장 ③ 8장.
- 정답: ③.
- 해설: "5가 네 장, 10이 네 장입니다. 두 숫자 종류를 기다리지만 카드 장수는 총 여덟 장입니다."

**4-3. 한 종류, 네 장**

- 내 카드: 9♣ 7♦ / 플랍: 6♥ 5♠ K♣.
- 질문: "8이 나오면 스트레이트입니다. 스트레이트 아웃츠는 몇 장인가요?"
- 보기: ① 1장 ② 4장 ③ 8장.
- 정답: ②.
- 해설: "5–6–7–□–9의 빈칸은 8입니다. 아직 보이지 않은 8은 네 문양으로 네 장입니다."

### 요약 문구

"완성할 족보를 먼저 정하고, 필요한 카드의 실제 장수를 세세요. 기본 플러시 드로우는 9장, 오픈엔디드는 8장, 거샷은 4장입니다."

## 7. 레슨 5 — 턴과 리버: 남은 기회가 다르다

제안 ID: `remaining-chances`.

### 목표

다음 한 장과 리버까지 두 장의 완성 확률을 구분하고, 확률을 승률이나 베팅 정답으로 오해하지 않는다.

### 화면 순서와 설명 문구

1. 도입: "아웃츠가 같아도 앞으로 보는 카드 수가 다르면 완성 가능성이 달라집니다."
2. 플랍 예시: K♠ Q♠ / 플랍 9♠ 3♠ 2♦.
   - "스페이드 네 장입니다. 턴과 리버, 두 장이 아직 공개되지 않았습니다. 두 장을 모두 보게 된다면 둘 중 하나가 스페이드여도 플러시가 완성됩니다."
3. 턴 예시: 같은 내 카드·플랍에 7♣.
   - "스페이드 아웃츠는 그대로 9장입니다. 하지만 이제 리버 한 장만 남았습니다."
4. 리버 실패 예시: J♦.
   - "플러시는 완성되지 않았습니다. 리버가 공개되면 다음 공용 카드는 더 없습니다. 이번 결과가 앞으로의 확률을 증명하는 것은 아닙니다."
5. 확률 설명: 아래 표와 2·4 법칙을 짧은 설명 두 단계로 나누어 보여준다.
6. 아래 고정 퀴즈 3개.
7. 요약.

### 확률 표와 표시 조건

| 목표 | 플랍에서 턴 한 장 | 플랍에서 리버까지 두 장 | 턴에서 리버 한 장 |
|---|---:|---:|---:|
| 플러시: 9아웃츠 | 약 19% | 약 35% | 약 20% |
| 오픈엔디드: 8아웃츠 | 약 17% | 약 31% | 약 17% |
| 거샷: 4아웃츠 | 약 9% | 약 16% | 약 9% |

- 표는 공개 정보가 내 카드와 보드뿐이며, 해당 아웃츠가 완성 카드로 유지되는 기본 모델이다. 상대의 실제 카드가 추가로 공개되면 그대로 적용하지 않는다.
- 플랍 한 장은 `n / 47`, 턴 한 장은 `n / 46`, 플랍 두 장은 `1 - ((47-n)/47) × ((46-n)/46)`를 반올림한 값이다. 이 수식은 학습자에게 암기시키지 않는다.
- 두 장 수치는 턴·리버를 모두 보게 된다는 조건이다. 플랍의 콜 한 번으로 리버까지 항상 볼 수 있다는 뜻이 아니다.
- 표 제목은 '목표한 드로우의 완성 확률'이다. 승률·에쿼티라고 표시하지 않는다.
- 모바일 표는 열 폭을 줄이려고 문구를 생략하기보다 한 장/두 장 조건을 읽을 수 있는 작은 비교 묶음으로 나눌 수 있다.

2·4 법칙 설명 문구:

"빠르게 어림잡을 때는 다음 한 장이면 아웃츠에 2를, 플랍에서 리버까지 두 장이면 4를 곱할 수 있습니다. 9아웃츠라면 약 18%와 약 36%로 추정합니다. 정확한 계산과 차이가 있는 근삿값입니다. 아웃츠가 많은 복합 상황까지 그대로 정확하다고 생각하지 마세요."

### 고정 퀴즈

**5-1. 남은 기회 비교**

- 동일한 9아웃츠 플러시 드로우의 플랍 상황과, 완성되지 않은 턴 상황을 나란히 설명한다.
- 질문: "다른 조건이 같다면 플러시 완성 가능성이 더 높은 것은?"
- 보기: ① 플랍에서 턴·리버 두 장을 모두 보는 경우 ② 턴에서 리버 한 장을 보는 경우.
- 정답: ①.
- 해설: "두 장을 모두 볼 수 있다면 완성 카드를 만날 기회가 더 많습니다. 같은 9아웃츠여도 남은 기회는 다릅니다."

**5-2. 턴의 빠른 추정**

- 내 카드: K♠ Q♠ / 플랍: 9♠ 3♠ 2♦ / 턴: 7♣.
- 질문: "플러시 9아웃츠로 리버 한 장을 기다립니다. 2·4 법칙으로 어림잡은 완성 확률은?"
- 보기: ① 약 18% — 9×2 ② 약 36% — 9×4.
- 정답: ①.
- 해설: "남은 카드는 리버 한 장이므로 2를 곱해 약 18%로 추정합니다. 정확한 기본 계산은 약 20%이며, 여기서는 명시한 근사 방법을 묻습니다."

**5-3. 두 장 확률의 조건**

- 질문: "플랍에서 9아웃츠×4로 얻은 약 36%는 어떤 경우의 근삿값인가요?"
- 보기: ① 턴 한 장만 보는 경우 ② 턴과 리버 두 장을 모두 보는 경우 ③ 상대를 반드시 이기는 확률.
- 정답: ②.
- 해설: "4를 곱하는 것은 플랍에서 리버까지 두 장을 보는 경우의 완성 가능성 추정입니다. 다음 한 장의 확률도, 상대를 이길 확률도 아닙니다."

### 요약 문구

"확률을 보기 전에 남은 카드 수를 확인하세요. 다음 한 장과 리버까지 두 장은 다른 조건입니다. 완성 확률은 승률이 아닙니다."

## 8. 레슨 6 — 완성돼도 반드시 이기는 것은 아니다

제안 ID: `draw-cautions`.

### 목표

내 족보의 개선과 상대를 이기는 것을 구분하고, 두 드로우의 아웃츠가 겹치면 중복 계산하지 않는다.

### 화면 순서와 설명 문구

1. 도입: "드로우를 찾았다고 과신하지 마세요. 완성 카드는 내 패를 개선하지만 승리를 보장하지 않습니다."
2. 낮은 플러시 예시: 8♥ 7♥ / 플랍 K♥ 4♥ 2♣ / 턴 Q♥.
   - 내 플러시 다섯 장: K♥ Q♥ 8♥ 7♥ 4♥.
   - "플러시가 완성됐습니다. 그런데 상대 카드가 아직 보이지 않는다면 누가 더 강한지는 확정할 수 없습니다."
3. 가능한 상대 예시: 상대가 A♥ J♥인 경우, 상대 플러시 A♥ K♥ Q♥ J♥ 4♥도 실제 카드로 보여준다.
   - "이 상대라면 현재 내 플러시보다 더 높은 플러시입니다. 이는 가능한 사례이지 상대가 반드시 이 카드를 들고 있다는 뜻은 아닙니다. 리버 전 게임의 최종 승패도 단정하지 않습니다."
4. 중복 예시: 8♥ 7♥ / 플랍 6♥ 5♣ K♥.
   - "하트 한 장이면 플러시, 4나 9면 스트레이트입니다."
   - "4♥와 9♥는 두 목표에 모두 해당하지만 각각 한 장입니다. 같은 카드를 두 번 세면 안 됩니다."
   - 보조 해설: 합쳐 세면 9+8−2=15장이다. 숫자 15 암기나 복합 확률은 채점하지 않는다.
5. 아래 고정 퀴즈 3개.
6. 요약.

### 고정 퀴즈

**6-1. 완성과 승리 구분**

- 내 카드: 9♣ 8♣ / 플랍: K♣ 5♣ 2♦ / 턴: J♣.
- 질문: "플러시가 완성됐습니다. 상대 카드가 안 보이는 지금, 맞는 설명은?"
- 보기: ① 플러시니까 승리가 확정됐다 ② 더 높은 플러시나 다른 강한 족보가 가능하므로 승리를 확정할 수 없다.
- 정답: ②.
- 해설: "내 플러시는 완성됐지만 상대가 A♣ Q♣라면 더 높은 플러시입니다. 내 족보를 안다는 것과 승패를 안다는 것은 다릅니다."

**6-2. 겹치는 카드 세기**

- 내 카드: J♦ 10♦ / 플랍: 9♦ 8♣ 2♦.
- 질문: "7♦는 플러시와 스트레이트를 모두 완성합니다. 아웃츠 합계에서 7♦를 몇 번 세야 할까요?"
- 보기: ① 한 번 ② 두 번.
- 정답: ①.
- 해설: "한 장이 두 목표를 완성해도 실제 카드는 한 장입니다. Q♦도 두 목록에 겹치므로 각각 한 번만 셉니다."

**6-3. 가능성만으로 행동을 확정하지 않기**

- 질문: "플러시 드로우가 있으면 상대가 얼마를 베팅하든 무조건 따라가도 될까요?"
- 보기: ① 가능성이 있으니 무조건 따라간다 ② 완성 가능성만으로 결정할 수 없으며 베팅 금액 등도 필요하다.
- 정답: ②.
- 해설: "드로우가 있다는 정보만으로 콜의 가치를 확정할 수 없습니다. 베팅 금액과 팟 크기를 함께 판단하는 방법은 이후 과정에서 배웁니다. 이 파트는 그 행동의 계산까지 다루지 않습니다."

### 요약 문구

"완성 가능성과 승리 가능성은 구분하세요. 두 드로우가 겹쳐도 같은 카드는 한 번만 세고, 드로우가 있다는 이유만으로 행동을 확정하지 마세요."

## 9. 레슨 7 — 미래 가능성 종합 도전

제안 ID: `draw-challenge`.

### 목표와 구성

- 앞 레슨에서 등장하지 않은 카드 상황에서 같은 판단 순서를 적용한다.
- 시작 안내 한 단계 → 아래 고정 6문제 → 요약·기존 결과 화면.
- 안내: "현재 패, 필요한 카드, 아웃츠, 남은 기회를 차례로 살펴보세요. 확률은 족보 완성 가능성이며 승리를 보장하지 않습니다."
- 정답 확인 뒤에는 기존 방식으로 해설을 제공한다. 새로운 시험 전용 화면은 만들지 않는다.

### 고정 퀴즈

**7-1. 현재 패와 드로우를 함께 읽기**

- 내 카드: A♣ 10♣ / 플랍: A♦ 7♣ 3♣.
- 질문: "현재 패와 앞으로의 가능성을 올바르게 설명한 것은?"
- 보기: ① 이미 플러시다 ② A 원 페어이며 플러시 드로우도 있다 ③ A 원 페어이므로 드로우는 없다.
- 정답: ②.
- 해설: "두 A로 원 페어입니다. 클럽도 네 장이므로 클럽 한 장이 더 나오면 플러시가 됩니다."

**7-2. 내 카드와 보드의 문양 합치기**

- 내 카드: Q♦ 8♠ / 플랍: K♦ 6♦ 2♦.
- 질문: "다음 한 장으로 내 플러시를 완성할 문양은?"
- 보기: ① 스페이드 ② 다이아몬드 ③ 내 카드가 다른 문양이므로 어떤 문양도 불가능하다.
- 정답: ②.
- 해설: "내 Q♦와 보드의 다이아몬드 세 장으로 네 장입니다. 다이아몬드 한 장을 더 받으면 플러시입니다."

**7-3. 오픈엔디드의 완성 카드 찾기**

- 내 카드: J♣ 10♦ / 플랍: 9♥ 8♠ 2♣.
- 질문: "스트레이트를 완성할 숫자를 모두 고르세요."
- 복수 선택 보기: ① 7 ② Q ③ J ④ 6.
- 정답: ①·②.
- 해설: "8–9–10–J의 양끝에 7 또는 Q가 붙으면 연속된 다섯 숫자입니다. J는 페어만 만들고, 6은 7이 빠져 있습니다."

**7-4. 거샷의 아웃츠**

- 내 카드: 10♣ 8♦ / 플랍: 7♥ 6♠ A♣.
- 질문: "상대 카드 등 추가 정보가 없을 때, 다음 한 장으로 스트레이트를 완성하는 아웃츠는?"
- 보기: ① 9 한 종류이므로 1장 ② 9 네 문양으로 4장 ③ 양끝 두 종류로 8장.
- 정답: ②.
- 해설: "6–7–8–□–10에서 9가 필요합니다. 아직 보이지 않은 9는 네 문양으로 네 장입니다. 페어를 만드는 카드는 여기서 세지 않습니다."

**7-5. 남은 한 장의 추정 방법**

- 내 카드: K♥ 9♥ / 플랍: J♥ 5♥ 2♣ / 턴: 3♦.
- 질문: "플러시 9아웃츠로 리버를 기다립니다. 2·4 법칙의 올바른 추정은?"
- 보기: ① 9×2로 약 18% ② 9×4로 약 36%.
- 정답: ①.
- 해설: "이제 리버 한 장만 남았으므로 2를 곱합니다. 이 값은 근삿값이며 상대를 이길 확률을 뜻하지 않습니다."

**7-6. 완성 뒤에도 승리 단정 금지**

- 내 카드: Q♠ J♠ / 플랍: 9♠ 4♠ 2♥ / 턴: 7♠.
- 질문: "플러시가 완성됐습니다. 올바른 설명은?"
- 보기: ① 완성됐으니 상대 카드를 몰라도 승리가 확정된다 ② 상대에게 더 높은 플러시가 있을 수 있으므로 승리를 확정할 수 없다.
- 정답: ②.
- 해설: "내 플러시는 Q 하이입니다. 상대가 A♠ 10♠라면 현재 더 높은 플러시입니다. 완성 여부와 승리 여부는 구분해야 합니다."

### 마지막 요약 문구

"지금의 패를 읽고, 좋아질 카드를 찾고, 장수와 남은 기회를 연결하세요. 드로우는 가능성이며 완성도 승리도 보장하지 않습니다."

## 10. 레슨만 구현할 때의 연결·재사용 범위

이 절은 상세 구현계획이 아니라 교육 내용을 화면에 옮길 때 지킬 경계다. 상세안 승인 뒤 실제 파일별 구현계획을 작성한다.

- Part 3 콘텐츠와 카탈로그를 등록하고 기존 홈·레슨 목록·레슨·결과 화면을 재사용한다.
- 설명, 카드 공개, 단일 선택, 복수 선택, 요약은 기존 Step 종류를 사용한다.
- 기존 선택 문제의 카드 데이터는 플랍 세 장으로 제한되어 있다. 턴·리버 질문을 글자로만 우회하지 않고 공개 단계와 카드 수를 최소 확장한다. 타입·렌더러·검증·테스트를 함께 맞춘다.
- 아웃츠 목록은 실제 카드를 표시해야 하지만 '족보 예시 다섯 장' 전용 데이터를 억지로 재사용하지 않는다. 필요한 최소 표현은 구현계획에서 정한다. 새 게임 엔진·족보 자동 판정·범용 퀴즈 플랫폼은 만들지 않는다.
- 상대 비교는 같은 공용 보드와 내 개인 카드, 가정한 상대 개인 카드를 표시하고 각 족보 구성 카드를 강조한다. 상대 개인 카드는 실제 공개된 패가 아닌 가정임을 명시하며 상대 패를 추론하는 시뮬레이터는 만들지 않는다.
- 저장·답 복원·해설·이전/다음·스크롤·도전 재도전은 기존 공통 엔진의 정책을 유지한다. 기존 Part와 저장 데이터를 초기화하지 않는다.
- Part 3 추가연습은 등록하지 않으며 목록과 결과에서 없는 연습으로 연결하지 않는다. 다른 Part의 연습은 그대로 유지한다.
- '드로우' 명칭을 이후 공통 규칙에도 반영한다. 이번 상세안 단계에서는 기존 콘텐츠를 관련 없이 일괄 수정하지 않는다.
- React와 브라우저 저장을 유지한다. DB·Spring Boot·로그인·새 의존성은 이번 범위가 아니다.

## 11. 검증 기준

### 설계 검토

- 총 7레슨, 기본 퀴즈 18문제와 종합 6문제인지 확인한다.
- 한 카드 상황에서 같은 카드가 중복되지 않아야 한다. 다른 문제 간 카드 재사용은 허용한다.
- 완성 예시의 다섯 장이 실제 내 카드와 보드에서 구성되어야 한다.
- 모든 정답은 앞 설명으로 도출할 수 있어야 한다. 종합 도전은 앞의 카드 상황과 달라야 한다.
- 아웃츠 문제는 목표 족보와 공개 정보의 범위를 명시해야 한다.
- 확률 표는 계산값, 2·4 법칙 문제는 근삿값으로 구분하고 승률로 표기하지 않아야 한다.
- 추가연습을 이번 구현에 섞지 않아야 한다.

### 구현 완료 시

- 콘텐츠 검증·타입 검사·전체 테스트·lint·빌드가 통과해야 한다.
- Part 3에서 선택·제출 → 홈/목록 → 이어하기 → 새로고침 때 같은 문제·선택·해설이 복원되어야 한다.
- 다음·이전으로 이동할 때 문제 시작 부분이 보이고 점수가 중복 집계되지 않아야 한다.
- 턴은 공용 카드 네 장, 리버는 다섯 장이 보이고 아직 공개되지 않은 카드 값을 노출하지 않아야 한다.
- 4/6은 재도전 필요, 5/6은 통과로 표시되고 재도전 중에는 이어하기가 우선이어야 한다.
- Part 3의 추가연습 링크가 없으며 Part 1·2의 기존 연습과 저장은 유지되어야 한다.
- 모바일 390×844와 데스크톱 1440×900에서 카드·아웃츠 목록·확률 조건을 읽을 수 있어야 한다.
