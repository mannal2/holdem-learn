# Part 1 레슨 시각화 작업

2026-10-03 사용자 승인 계획을 바탕화면 저장소에서 구현한다.

## 범위와 기준

- 기존 8개 레슨·Step 순서·ID·보기 ID·정답·통과 기준은 유지한다.
- 설명을 핵심 한두 문장과 실제 카드·6인 자리 그림으로 바꾼다.
- 표기 읽기 문제는 제출 후 카드 공개, 카드 판단 문제는 제출 전 카드 표시.
- 포지션 설명은 UTG·HJ·딜러 버튼을 각 그룹의 예시 자리로 사용한다.
- 후반 버튼 뒤에는 SB·BB가 남는다. 앞선 폴드는 실제 학습 조건에 있을 때만 표시한다.
- 추가연습 데이터와 기존 단순 포지션 그림은 유지한다.
- 저장·이동·채점 엔진은 변경하지 않는다.

## 진행 및 검증

1. 시각 표시 테스트 작성 → 기존 코드에서 실패 확인.
2. 기존 카드와 자리 CSS를 재사용해 시각화·문구 축약 → 단위 테스트 확인.
3. 모바일·데스크톱 전체 레슨 및 저장 복원 확인 → lint·빌드·브라우저 검사.

결정: 작업 위치·커밋 정책은 사용자 지시를 우선해 새 워크트리와 자동 커밋 없이 기존 폴더에서 진행한다. 별도 이미지 파일·라이브러리·저장 마이그레이션은 추가하지 않는다.

결정: 질문의 카드 표기를 모두 제거하면 질문·해설만 읽는 오답 결과에서 카드 정보가 사라진다. 시각화는 유지하면서 특징·비교·강도·종합 문제의 짧은 카드 표기를 남긴다. 질문은 일반 문구만 있을 때보다 조금 길지만, 결과에서 무엇을 틀렸는지 알 수 있다.

진행: 신규 시각 테스트 12개의 실패를 확인한 뒤 구현하고 통과했다. 새 개인 카드 중복 검사도 2개 테스트의 실패를 확인한 뒤 구현했다. 최초 전체 단위 검사에서 종합 문제 표기 누락이 발견돼 짧은 카드 표기를 복구했다.

읽기 전용 최종 검토: ID·종류·순서·보기 ID·정답·통과 기준 일치, 카드 및 포지션 데이터 일치. Important 1건(일부 오답 결과의 카드 정보 소실), Critical·Minor 없음. 결과 화면 테스트 3개의 실패 확인 후 해당 레슨의 질문에 짧은 카드 표기를 복구했다. 이전 요청의 변경과 실제 기기·Safari·Firefox는 이번 코드 검토 범위가 아니다.

최종 검증: 단위·컴포넌트 테스트 188개, Chromium 모바일 390×844·데스크톱 1440×900 브라우저 테스트 44개, lint·TypeScript 검사·빌드 통과. 표기·비교·후반 포지션의 모바일 스크린샷을 직접 확인했다. 기존 저장 진도는 초기화하지 않았고, 8개 레슨의 모든 단계와 다른 Part·추가연습 흐름을 테스트용 브라우저에서 확인했다. 실제 휴대전화·Safari·Firefox·실제 화면 읽기 도구는 미검증이다. 검토 지적은 결과 회귀 테스트 RED→GREEN 및 전체 재검증으로 해결했으며 보류한 Minor는 없다.
