# Part 4 문장 수정 계획 — 짧고 쉬운 표현

2026-10-06 개정. 상태: 사용자 검토용, 앱 문구 수정 전. 기존 59398ee의 장문 수정안을 이 문서로 대체한다. 사용자는 구어체 통일보다는 짧고 이해하기 쉬운 문장을 원한다.

## 검토 범위와 방향

7레슨·64화면의 설명·조건·도식과 31문제의 질문·보기·해설을 대상으로 한다. 콘텐츠 원문 검토에서 찾은 문제 목록은 유지하되, 앞 계획의 길어진 수정안을 줄였다. 앱은 아직 수정하지 않았다.

기준은 ‘짧은데 뜻이 생략되지 않은 문장’이다. ‘갱신·무게·개선·내부 순위’ 같은 추상어를 실제 패·행동으로 바꾼다. 모든 표현을 친근한 구어체로 늘리지 않는다.

| 화면 역할 | 작성 기준 |
|---|---|
| 상단 목표 | 무엇을 배우는지 한 문장 |
| 본문 | 핵심과 필요한 이유를 1~2문장. 여러 후보의 이유는 짧은 항목으로 나눔 |
| 조건 | ‘가정:’ 뒤에 상대의 습관만 명시. 카드·자리·금액은 짧은 사실로 표시 |
| 질문 | 판단할 대상과 행동이 드러나는 한 문장 |
| 선택지 | 판단 하나 또는 밀접한 두 판단. 상세 이유와 주의점은 해설로 이동 |
| 후보 카드 아래 | 현재 족보 / 변화 표시 / 짧은 이유. 조건 전체를 반복하지 않음 |
| 해설 | 왜 그 답인지 1~2문장. 순위·가능성 단정의 주의점은 필요한 문제에만 덧붙임 |

문장 수를 맞추느라 필수 조건을 지우지는 않는다. 특히 ‘페어도 뚜렷한 드로우도 없음’을 단순히 ‘약한 패’로 바꾸면 조건이 넓어지므로 원래 의미를 유지한다. 긴 문장을 잘게 나누기만 하는 방식도 피한다.

‘가능성 ↑ / 가능성 ↓ / 판단 유지’, 카드·금액·행동·정답 의미·보기 순서·ID·64화면·31문제·10/12 통과는 유지한다. 새로운 가정이나 미래 행동은 추가하지 않는다.

## 1. 공통 조건 수정안

| 현재 표현 | 짧고 쉬운 수정안 |
|---|---|
| ‘입문용 가정: 자리에 따라 참가 범위를 바꾸며 버튼에서 초반보다 넓게 참가’ | ‘가정: 이 상대는 초반에는 좋은 패로 참가하지만, 앞사람들이 모두 폴드한 버튼에서는 조금 덜 좋은 패로도 참가해요.’ |
| ‘이번 판단의 가정: 페어도 뚜렷한 드로우도 없는 패로 두 번 연속 베팅하는 경우는 드물어요.’ | ‘가정: 이 상대는 페어도 뚜렷한 드로우도 없으면 플랍·턴에 연속 베팅을 잘 하지 않아요.’ |
| ‘플러시 가능 보드에서 원 페어로 크게 베팅하거나, 미완성 패로 세 번 연속 블러프하는 경우는 드물어요.’ | ‘가정: 이 상대는 플러시가 가능한 공용 카드에서 원 페어로 크게 베팅하는 일이 드물어요. 페어도 없고 드로우도 완성되지 않은 패로 세 번 연속 블러프하는 일도 드물어요.’ |
| ‘원 페어로 턴 베팅을 크게 다시 올리는 경우는 드물어요. 블러프는 가능해요.’ | ‘가정: 이 상대는 원 페어로 턴에 크게 레이즈하는 일이 드물어요. 블러프 레이즈는 가능해요.’ |
| ‘미완성 패로 세 번 연속 블러프하는 경우는 드물어요.’ | ‘가정: 이 상대는 페어도 없고 드로우도 완성되지 않은 패로 세 번 연속 블러프하는 일이 드물어요.’ |
| ‘상대의 포스트플랍 성향은 모름’ | ‘플랍 이후 어떤 패로 베팅하거나 체크하는지는 아직 모름’ |
| ‘리버 블러프 빈도는 모름’ | ‘리버에서 블러프를 얼마나 자주 하는지는 아직 모름’ |
| ‘앞에 참가한 사람 없이 첫 레이즈 · 같은 상대·보유 칩’ | ‘앞사람 모두 폴드 후 첫 레이즈 · 같은 상대, 같은 보유 칩’ |
| ‘6인 · 각 200칩(큰 블라인드 100개) · SB 1칩 / BB 2칩’ | ‘6명 · 각 200칩 · 스몰 블라인드(SB) 1칩 / 빅 블라인드(BB) 2칩’ |

‘드묾’은 ‘불가능’이 아니다. 조건이 길어도 서로 다른 두 습관은 한 문장으로 압축하지 않는다. 반복되는 ‘이번 문제에서는 …라고 가정해요’ 대신 ‘가정:’으로 교육용 조건임을 표시한다.

## 2. 설명·요약·도식 수정안

페이지 번호는 각 레슨 안의 순서다. 문제 화면은 다음 절에 따로 정리했다.

| 위치 | 현재 표현 또는 문제 | 수정안 |
|---|---|---|
| Part 소개 | ‘후보의 가능성을 갱신’ | ‘프리플랍부터 리버까지, 카드와 행동을 보고 상대가 가질 만한 패를 생각해요.’ |
| 1·목표 | ‘상대 자리와 첫 행동으로 가능한 패 종류’ | ‘상대의 자리와 첫 행동을 보고 가능한 패를 생각해요.’ |
| 1·1 | 어색한 레인지 정의·갱신 표현 | ‘상대가 가질 수 있는 여러 패의 범위를 레인지라고 해요. 새 카드와 행동을 보며 후보를 다시 판단해 볼게요.’ |
| 1·4 | ‘첫 레이즈는 앞선 레이즈가 없어요.’ | ‘아무도 레이즈하지 않았을 때 처음 올리면 첫 레이즈예요. 앞사람의 레이즈를 다시 올리면 재레이즈예요.’ |
| 1·7 | ‘전체 레인지나 같은 확률을 뜻하지 않아요.’ | ‘가능한 패 중 네 가지 예시예요. 다른 패도 가능하며, 네 후보의 가능성이 같다는 뜻은 아니에요.’ |
| 1·8 | ‘같은 A~D가 플랍을 만나요.’ | ‘다음에는 같은 A~D를 공용 카드와 함께 살펴봐요.’ |
| 2·목표 | ‘앞서 잡은 같은 후보들의 현재 패’ | ‘같은 후보들이 플랍에서 어떤 족보와 드로우를 갖는지 확인해요.’ |
| 2·1 | ‘공용 카드를 붙여 봐요.’ | ‘네 후보를 공용 카드와 함께 보고, 현재 족보를 확인해요.’ 앞 문장의 레이즈·콜 유지. |
| 2·6 | ‘별도 비교예요. J 원 페어가 있고 하트도 네 장…’ | ‘다른 카드 예시예요. J 원 페어와 하트 4장이 있어, 원 페어와 플러시 드로우를 함께 가졌어요.’ |
| 3·목표/1 | ‘이유와 팟 대비 크기를 연결’ | 목표: ‘베팅의 이유와 팟에 비해 얼마나 큰 베팅인지 살펴봐요.’ 본문 끝: ‘각 후보라면 왜 베팅할까요?’ |
| 3·4 | ‘더 약한 패의 콜’, ‘다음 카드의 개선’ | 본문을 짧은 후보별 항목으로 표시: ‘A·B: 더 약한 패에게 콜을 받아 칩을 더 얻으려는 베팅.’ / ‘C: 다른 사람의 폴드를 노리는 베팅. 콜을 받아도 다음 스페이드로 플러시가 될 기회가 있음.’ / ‘D: 페어 없이 다른 사람을 폴드시키려는 블러프.’ 후보가 실제 패라고 단정하지 않도록 ‘각 후보라면’이라는 제목 맥락 유지. |
| 3·6 | ‘처음에 어떤 후보가 얼마나 포함됐는지’ | ‘가장 강한 패라고 가장 유력한 것은 아니에요. 상대가 어떤 패로 참가하고 베팅하는지도 알아야 해요.’ 도식 ‘지금의 한계’ → ‘아직 모르는 정보’. |
| 3·8 | ‘정확한 순위는 보류’ | ‘A~D는 모두 가능해요. 어느 패가 더 유력한지는 다음 카드와 행동을 더 봐야 해요.’ |
| 4·목표/3 | ‘이전 판단을 갱신’, ‘가정과 새 행동을 함께 보고’ | 목표: ‘턴 카드와 두 번째 베팅을 보고 후보를 다시 판단해요.’ 본문: ‘상대가 턴에서도 베팅했어요. 위의 가정에 따라 어떤 후보의 가능성이 달라질지 생각해 보세요.’ 조건은 유지. |
| 4·5 | 장문의 가능성·판단 유지 설명 | ‘D로 두 번 베팅하는 일은 드물다고 정했으므로 D의 가능성을 낮게 봐요. A·B·C는 이전 판단을 유지하며, 세 후보의 가능성이 같다는 뜻은 아니에요.’ |
| 4·6 조건/7 | ‘반복 공격 습관’, ‘상대 조건 때문에’ | 조건: ‘같은 카드와 베팅이라도, 약한 패로 연속 베팅하는지는 모르는 상대라면?’ 설명: ‘D의 가능성을 낮춘 이유는 턴 카드가 아니라 두 번의 베팅과 상대의 습관이에요.’ 팟 변화 문장 유지. |
| 4·8 | 변화 정의 | ‘가능성 ↑: 이전보다 더 유력함’ / ‘가능성 ↓: 이전보다 덜 유력함’ / ‘판단 유지: 이전 판단을 바꿀 근거가 없음’ |
| 5·1/5 | ‘여전히 남은 패’, ‘낮은 후보’ | 1페이지: ‘새 카드로 족보가 바뀐 후보와 그대로인 후보를 확인해요.’ 5페이지 제목: ‘어떤 패가 더 유력할까요?’ 본문: ‘이 가정에서는 A·C가 더 유력하고 B·D의 가능성은 낮게 봐요. A와 C 중 어느 쪽이 더 유력한지는 아직 알 수 없어요.’ 완전히 제외하지 않는다는 주의는 Q14 해설에 유지. |
| 5·7 | ‘후보별 설명을 이어서 만들었어요.’ | ‘각 후보가 지금까지의 카드와 행동에 얼마나 잘 맞는지 살펴봤어요.’ 도식: ‘턴: 두 번의 베팅과 상대 습관 → D 가능성 ↓’ / ‘리버: 완성된 족보와 큰 베팅 → A·C가 더 유력’. |
| 5·8 | ‘이어 붙여요.’ | ‘마지막 베팅만 보지 말고, 처음부터 나온 카드와 행동을 함께 봐요.’ |
| 6·1 | ‘별도의 비교 전개’ | 제목: ‘다른 카드와 행동이 나왔다면?’ 본문: ‘같은 후보와 플랍에서, 이후 카드와 행동만 바꾼 별도 예시예요.’ |
| 6·4 | ‘팟 조절’, ‘드로우 공격 중단’ | ‘원 페어로 팟을 키우지 않으려 체크하거나, 드로우로 추가 베팅 없이 다음 카드를 보려 했을 수 있어요. 셋도 체크할 수 있어요.’ |
| 6·6 | 레이즈 총액 혼동 | ‘BB가 8칩을 베팅하자 상대는 총 24칩으로 레이즈했어요.’ 조건에 ‘24칩은 추가액이 아니라 이번 베팅의 총액’ 명시. |
| 6·10 | ‘행동의 모양을 공식’, ‘공격 약화’, ‘새 완성’ | 제목: ‘행동 하나로 패를 단정하지 않아요.’ 목록: ‘계속 베팅해도 처음부터 가장 좋은 패였다고 단정할 수 없어요.’ / ‘체크는 원 페어·드로우·강한 패로도 가능해요.’ / ‘늦은 레이즈는 새로 완성된 패·기존의 강한 패·블러프 모두 가능해요.’ |
| 7·목표/1/14 | 추상적인 적용·연결 표현 | 목표: ‘새로운 세 판에서 상대가 가질 만한 패를 판단해요.’ 안내: ‘각 판을 프리플랍부터 리버까지 네 문제로 봐요. 12문제 중 10문제 이상 맞히면 통과예요.’ 요약: ‘새 카드와 행동을 보고 더 유력한 후보와 그 이유를 판단했어요.’ |

레슨 1·2페이지는 이미 승인한 쉬운 문장이므로 유지한다. 모든 본문을 장문으로 늘리지 않으며, 명확한 셋·탑 페어·스페이드 장수·팟 비교 설명은 유지한다.

## 3. 31개 문제 수정안

보기는 짧은 문장이나 문장형 항목으로 쓴다. 정답 보기만 유난히 길어지는 것을 피하고, 새 문구에서도 정답 의미와 확정/가능의 차이를 유지한다. 표에서 다루지 않은 명확한 보기·질문은 유지한다.

| 문제/화면 | 질문·보기·해설 수정안 |
|---|---|
| Q01 · 1/3 | 질문: ‘초반 자리와 비교하면, 버튼에서 처음 레이즈한 상대는 어떤 패들을 가질 수 있을까요?’ 정답: ‘높은 카드뿐 아니라 페어·같은 무늬 연결 카드도 고려한다.’ 해설: ‘앞사람들이 폴드한 버튼에서는 덜 좋은 패로도 참가할 수 있어요. 강한 패를 포함해 더 다양한 패를 생각해요.’ |
| Q02 · 1/5 | 정답: ‘버튼 자리와 앞선 레이즈를 다시 올렸다는 점을 함께 본다.’ 해설: ‘같은 버튼이어도 첫 레이즈와 재레이즈는 달라요. 앞사람의 행동도 보고 가능한 패를 판단해요.’ |
| Q03 · 1/6 | 질문: ‘버튼에서 처음 레이즈한 상대가 가질 수 있는 패 종류를 모두 고르세요.’ 해설: ‘페어·높은 카드·같은 무늬 카드 등 여러 패가 가능해요. 그중 네 후보 A~D를 다음 화면부터 살펴봐요.’ |
| Q04 · 2/3 | 질문·보기 유지. 해설: ‘AK는 좋은 시작패지만, 이번 플랍에서는 A의 88이 셋이 되었어요. 공용 카드가 나오면 현재 족보를 다시 봐야 해요.’ |
| Q05 · 2/5 | 질문·보기 유지. 해설: ‘둘 다 페어가 없지만 C는 다음 스페이드로 플러시가 될 수 있어요. 현재 족보가 같아도 좋아질 기회는 달라요.’ |
| Q06 · 2/7 | 정답: ‘가장 강한 족보라고 상대가 가졌을 가능성도 가장 높은 것은 아니다.’ 질문·기존 해설 유지. |
| Q07 · 3/3 | 질문: ‘13칩 팟과 80칩 팟에서 같은 8칩 베팅은 어떻게 다를까요?’ 정답: ‘13칩 팟에서는 절반보다 크고, 80칩 팟에서는 10분의 1이다.’ 첫 오답: ‘둘 다 8칩이므로 팟에 비해 같은 크기다.’ 해설: ‘베팅액과 팟의 크기를 함께 봐요. 크기만으로 상대 패를 확정할 수는 없어요.’ H 표기 제거. |

## 4. 후보 카드 아래 문구

본문에 적힌 가정을 카드마다 길게 반복하지 않는다. 자세한 이유는 문제 해설에서 설명한다.

| 현재 표현 | 카드 아래 수정안 |
|---|---|
| ‘강한 패로 계속 받으려는 행동’ | ‘판단 유지 · 셋으로 콜을 받아 칩을 더 얻으려는 베팅 가능’ |
| ‘폴드 유도와 다음 카드 기대’ | ‘판단 유지 · 폴드를 노리며 다음 스페이드도 기다릴 수 있음’ |
| ‘반복 공격 조건’, ‘두 번째 공격이 드묾’ | ‘가능성 ↓ · 페어·뚜렷한 드로우 없이 두 번 베팅하는 일은 드문 상대’ |
| ‘강한 완성 패로 계속 고려’ | ‘판단 유지 · 셋으로 큰 베팅 가능’ |
| ‘위험 보드의 큰 베팅’, ‘플러시 가능 보드와 덜 맞음’ | ‘가능성 ↓ · 플러시 가능 상황에서 원 페어로 크게 베팅하는 일은 드문 상대’ |
| ‘미완성 패의 세 번째 공격’, ‘반복 블러프 조건’ | ‘가능성 ↓ · 드로우 완성 실패 뒤 세 번 연속 블러프는 드문 상대’ 페어 없는 D는 ‘페어 없이 세 번 연속 블러프는 드문 상대’. |
| ‘완성 뒤 레이즈가 연결됨’ | ‘가능성 ↑ · 플러시 완성 뒤 레이즈’ |
| ‘원 페어 레이즈가 드문 조건’ | ‘가능성 ↓ · 원 페어로 크게 레이즈하는 일은 드문 상대’ |
| ‘앞선 콜로 제외하지 않음’ | ‘판단 유지 · 셋으로 콜한 뒤 레이즈할 수 있음’ |
| ‘팟 조절 가능’, ‘공격 중단 가능’ | ‘원 페어로 팟을 키우지 않으려 체크 가능’ / ‘드로우로 추가 베팅 없이 다음 카드 보기 가능’ |
| ‘백도어 클럽 가능성/실패’ | 플랍: ‘페어 없음 · 턴·리버 모두 클로버면 플러시 가능’ / 턴: ‘페어 없음 · 턴이 클로버가 아니라 플러시 불가능’ |
| ‘계속 검토’, ‘블러프 가능, 빈도는 모름’ | ‘이 패로 베팅했을 가능성 유지’ / ‘블러프 가능 · 얼마나 자주 하는지는 모름’ |

현재 족보와 변화 줄을 분리한다. ‘셋’, ‘탑 페어’, ‘거샷 드로우 · 9가 필요’는 유지한다. 줄 수를 맞추려고 글자를 작게 줄이지 않는다. 모바일 두 열에서 긴 이유는 핵심만 남기고 상세 이유를 기존 해설에서 확인하도록 한다.

## 5. 행동 이력과 안내

- 이력은 현재처럼 단계·행동·칩을 짧게 표시한다. 장문으로 풀지 않는다.
- ‘BB가 총 6칩까지 콜’ → ‘BB가 4칩 추가 콜 · 팟 13칩’. 블라인드 2칩과 추가액을 구분한다. G도 동일하게 적용.
- 레이즈 총액은 ‘이번 베팅 총액 24칩/36칩’으로 명시한다. 기존 추가 콜 16칩/24칩 표시는 유지한다.
- 비교 예시·사례 E/F/G 구분은 유지한다. 이미 있는 A~D 후보와 섞이지 않게 필요한 경우 ‘판 E’로 짧게 표시하되, 판 이름 설명을 새로 늘리지 않는다.
- 레슨 제목 7개와 명확한 공통 버튼·카드 제목은 유지한다.

## 6. 실행과 검증 계획

1. 공통 조건·설명 수정 → 확인: 읽는 양을 늘리지 않고 상대 습관과 카드 사실이 명확하며, 필요한 가정이 남아 있음.
2. 31문제의 질문·보기·해설 수정 → 확인: 정답 의미·보기 ID·순서 유지, 정답 보기만 과도하게 길지 않음, H 잔여 표현 제거.
3. 후보 상태와 행동 이력 정리 → 확인: 현재 족보·가능성 변화 구분, 금액의 총액/추가액 정확, 제출 전 정답 근거 노출 없음.
4. 기존 콘텐츠 테스트·빌드 실행 → 확인: 64화면·31문제·카드·정답·통과 기준·저장 호환성 유지. 새 표현에 맞춰 문구 단정만 조정하며 내용 검사를 약화하지 않음.
5. 모바일·데스크톱 브라우저 검사 → 확인: 가로 넘침·조건과 보기의 줄바꿈·후보 상자 높이·저장한 선택과 해설 복원. 핵심 판단이 긴 설명 속에 묻히지 않는지 직접 확인.
6. 문서 갱신·diff 확인 후 한 번 커밋. 푸시는 별도 요청 시 수행.

수정안을 승인하면 콘텐츠 문구만 구현한다. 이번 개정에서는 앱 파일을 바꾸지 않았다. 문서 검증은 Q01~Q31 목록, 페이지 번호, 정답·조건의 의미를 원문과 대조하는 범위다.
