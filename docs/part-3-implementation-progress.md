# Part 3 구현 진행 기록

계획: `docs/superpowers/plans/2026-10-02-part-3-lessons.md`
상세안: `docs/part-3-lesson-design.md`

2026-10-02 사용자가 구현계획을 승인했다. 바탕화면 폴더에서 직접 실행한다.

- 사전 확인: Task 1의 stage/cardGroups/CommunityCards를 Task 2·3에서 동일한 이름으로 사용한다.
- 실행 방식 조정: 사용자 확정 작업 폴더를 유지하고 새 worktree를 만들지 않는다. Windows에서 별도 스킬 셸 스크립트 대신 이 한글 기록으로 진행 상태를 보존한다.
- 커밋·푸시 없이 변경 파일과 검증 결과를 제공한다. 승인한 계획의 범위를 따른다.
- Task 1: 완료. 기존 표시에서 신규 테스트 3개 실패 확인 후 최소 확장. 렌더러·테이블 6개 테스트와 빌드 통과.
- Task 2: 완료. 실패한 신규 검사 5개를 구현 후 검증기·카탈로그 12개 테스트 통과. 기존 코스 검증 오류 없음.
- Task 3: 완료. Part 3 미등록으로 테스트 실패 확인 → 등록 골격 → 빈 내용에서 28개 실패 확인 → 7레슨·24문제 구현. 콘텐츠·카탈로그 33개 테스트와 빌드 통과.
- Task 4: 완료. Part 3 목록·결과·복수 선택 및 턴 문제 복원·반응형·4/6과 5/6 경계를 검증했다. Part 3 브라우저 8개, 기존 파트를 포함한 전체 브라우저 30개 통과.
- Task 5: 완료. 한글 코드 해설·공통 규칙·상세안 상태·계획 체크리스트를 갱신했다. 최종 단위·컴포넌트 150개(28파일), lint, 빌드, git diff --check 통과.
- 검사 자료 수정: 종합 도전의 의도한 오답 선택을 명시하고, Testing Library 역할 쿼리에서 지원하지 않는 exact 옵션을 제거했다. 제품 정답·채점 기준은 변경하지 않았다.
- 전체 브라우저 검사 중 테스트 서버 종료로 ERR_CONNECTION_REFUSED 발생. 바탕화면 frontend에서 독립 서버를 실행한 뒤 전체 30개를 다시 실행해 통과했다. 서버는 사용자 확인용으로 유지한다.
- 최종 읽기 전용 코드 검토: Critical/Important 문제 없음. 문서가 구현 전으로 남아 있다는 Minor 지적을 실제 상태로 수정했다. 턴에서 미공개 리버 카드 이름을 숨기는 회귀 테스트도 추가했다.
- 검증 한계: Chromium의 모바일·데스크톱 화면 크기를 검사했다. 실제 휴대전화·Safari·Firefox는 검사하지 않았다. 사용자 브라우저의 저장 진도는 건드리지 않았으며 커밋·푸시는 하지 않았다.

## 완성 족보의 카드 출처 표시 — 사용자 승인 후속 수정

- 레슨 1의 플러시 완성, 레슨 3의 두 스트레이트 완성, 레슨 6의 상대 플러시 비교 총 네 단계를 수정했다. 보드·개인 카드 전체를 유지하고 족보 구성 카드를 즉시 강조한다. 비교에서는 같은 보드와 ‘가정한 상대 카드’를 표시한다.
- 기존 Step ID·순서·개수·24문제와 저장 키·진도 엔진은 유지했다. 족보 순서의 독립 예시와 아웃츠 후보 목록은 변경하지 않았다.
- 신규 화면 4개와 상대 카드 중복 검사에서 실패 확인 후 구현. 최종 단위·컴포넌트 156개, 모바일·데스크톱 전체 브라우저 36개, lint·빌드·git diff --check 통과. 네 화면 각각 이전/다음·새로고침 후 카드 소속과 강조를 복원함을 검사했다.
- 초기 브라우저 검사의 innerText와 textContent 간 줄바꿈 비교 오류는 테스트에 동일한 텍스트 읽기 방식을 적용해 수정했다. 화면이나 저장 로직의 문제는 아니었으며 전체 재검증했다.
- 모바일 화면 캡처에서 전체 카드 배치·강조·상대 가정 표시를 확인했다. 실제 휴대전화·Safari·Firefox는 미검증이며 커밋·푸시는 하지 않았다.
