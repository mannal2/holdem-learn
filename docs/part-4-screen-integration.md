## 저장 호환성

레슨 순서를 바꾼 다섯 레슨에 개정 번호 1을 부여한다. 구판은 개정 표시가 없고, 새 진도에는 `lessonRevision: 1`을 기록한다. 구판 위치·선택을 함께 변환하고 제출·오답·점수·완료·최고 기록은 유지한다. 다른 Part·연습 저장은 변경하지 않는다.

아래는 구판의 0부터 시작하는 각 화면 번호에 대응하는 새 번호다. 삭제된 설명은 관련 문제나 요약으로 연결한다.

- 플랍: `[0, 0, 0, 1, 1, 3, 2, 4]`
- 플랍 행동: `[0, 0, 1, 2, 3, 4, 5, 6]`
- 턴: `[0, 0, 1, 1, 2, 2, 3, 3]`
- 리버: `[0, 0, 1, 1, 2, 2, 3, 3]`
- 변형: `[0, 1, 1, 2, 2, 3, 3, 4, 4, 5]`

변환은 저장 유효성 검사 전에 실행하며, 변환 결과를 저장해 재로드 때 중복 적용하지 않는다. 저장 실패는 실패 상태로 알리고 기존 원본을 보존한다. Q02·Q04·Q05의 이전 문제 교체 정리는 기존 공통 규칙을 새 위치에서 적용한다.
